# 已知缺口与待决事项

盘点日期：2026-10-22。本页区分产品要求、原型现状与 Flutter 实现情况，不通过改写要求掩盖偏差。文档整理不等于业务修复或视觉验收。

## 保存失败仍可能提示成功

原型 createHabit 在写入失败后仍返回已创建的 ID；updateHabit 同样没有把 save() 失败传给页面。HabitEditor 据此提示“已保存”并关闭。内存操作成功与本地保存成功可能不一致。

要求：保存失败明确显示尚未保存，保留操作内容和重试；重试保存同一实体，不再次创建。Flutter 第二层已实现：编辑器保存失败不关闭，重试复用同一身份；其它业务和外观写入失败保留内存结果，显示未保存提示与重试入口。原型自身的缺陷未修改。

## 异常关闭后的进度损失

原型不逐秒保存，恢复只使用最后有效保存点。运行期间没有新的保存动作时，可能丢失整段尚未保存的有效用时；关闭期间不补时。当前逻辑已在 [保存与恢复限制](logic-and-interactions.md#实际保存触发点与恢复限制) 明确。

是否提高检查点频率、增加生命周期保存、或改变关闭后补时属于后续产品决策；本轮没有提高恢复精度，也不承诺后台持续执行。

## Flutter 本地业务已接入

Flutter 页面按 `lib/features/{focus,habits,review,settings,home,launch}/` 分模块；第二层由 `local_data` 组合计时与习惯事实，经 AppPrefs 的 `yike_snapshot_v1` 保存版本化快照。计时、计圈、番茄周期、幂等结算、跨日分配、习惯增删改与归档恢复、打卡撤销、回顾统计、偏好和重置已接线。

读取失败、损坏及不支持的快照版本会阻止业务写入并保留原始数据，提供重试读取和确认重置。运行中的 tick 不写存储；冷启动恢复最后保存的进度为暂停，不补算关闭期间用时。测试和原生演练范围见 [第二层自检](reviews/2026-10-22-layer-2.md)，不等于全部固定 Case 的视觉验收。

## 动效过程与视觉尚未验收

已整理数字、三表盘、打卡、回顾、导航及面板的动效意图。当前 Capture 使用减少动态效果并清零 CSS 动画/过渡时长，没有正式时间轴或过程帧交付。

弹层容器、键盘、安全区域、关闭和过渡使用 unified_popups；第一层已修正调用方式与内容布局。数字翻页等业务动效留待第三层。正常动效的中断、重播和快速连续操作需实际运行验证，不以静态截图推定过程；本轮没有建设录屏、动效采样、自动评分或 MCP 动效工具。

完整视觉复核仍是 partial：Producer 的 Review requirement/obligation ID 不一致，无法完成结构化汇总；未修改 Producer。模拟器 debug 偶见 Impeller inheritedOpacity 诊断，FlowSheet 头部在原生可访问性树中缺项；尚未做真机性能和大量历史数据压力测试。

## 资源精确复用的边界

Flutter 已有 DS 生成的 PNG 与清单；采集输出的资源声明与截图用于确认实际使用。通用逐资产 resolver、图标逐项摘要和 Target 本次真实使用的自动校验仍未建设。

遇到资源缺失、清单漂移或与固定 Evidence 摘要不符，应报告并处理对应 DS 版本，不静默替换成相似图或重绘。引用交付不承诺历史 SVG 原稿都可离线取回；历史归档 Blob 按原固定引用继续读取。

## 文档交付与 Evidence 的版本关系

本轮仅在 yike/docs 整理本地文档；文档复制到生成项目的脚本后续实现，当前由用户手动移动或复制。复制品不自动与 Handoff 绑定，本文也不是固定 Evidence。

后续交付需明确文档来源与版本，发现文档要求与固定 Case/Screenshot 冲突时记录双方来源。不得通过读取 Producer 当前文件或 active/latest 来替换固定 Evidence。

## 提醒与提示音

原型与 Flutter 均保存提醒开关、时间和提示音偏好，但不实际调度系统通知或播放完成声音。依据 [产品范围](product.md)，接入系统权限、通知与音频是后续实现范围。
