# 运行时与性能

## 启动与导航寿命

AppStartup 等待存储初始化后提供 AppPrefs 作用域；失败保留文件并显示重试。Bootstrap 只负责冷启动展示与进入根页面，不人为延时。从后台返回或打开设置不重新初始化业务，不重复播放启动。

根页面保留本次打开的选择与滚动。页面栈覆盖、根 Tab 隐藏和应用进入非前台时，局部装饰动画停止；再次可见按当前业务状态定位，不补播过去的秒数、打卡或完成视觉反馈。TickerMode 与生命周期、路由可见性共同控制绘制，不能只凭 Widget 仍 mounted 判断可见。

## 时间职责

业务时钟通过 clockProvider 注入，以真实经过时间计算有效用时；250ms pulse 是校准与到点处理机会，不是累计秒数来源。暂停不累计，到点封顶，阶段转换和幂等结算由 FocusEngine 与命令完成。

表盘绘制使用局部 Ticker 从当前会话时间锚点求连续进度。读数按秒变化，绘制可以按屏幕帧更新；每帧不提交业务快照、不结算、不写盘。减少动态效果时关闭装饰 Ticker，正常业务 pulse 与读数继续。

后台返回先校准全部会话，跳到真实进度，不逐帧补演隐藏时间。冷进程恢复仍按最后保存点暂停，不补算关闭期间。改变检查点频率、系统时钟调整处理或后台执行承诺属于单独产品决策；本轮维持既有恢复策略。

## 动画与资源寿命

控制器由创建它的 State 释放；监听在 Provider/State 对应清理入口撤销。使用共享输入驱动水面两份读数，避免独立时钟产生不同相位。缩略预览和启动品牌图保持静态。

静态原稿、动态进度和文字分层；可用 RepaintBoundary 隔离持续绘制，避免重建根页面或重算历史。缓存只保存可由输入重建的几何或资源，主题/尺寸变化使其失效。图片预热应解决实际首次使用闪烁，不无条件预解码整套大资源。

## 测量与预算

性能结论来自原生 profile 的 frame timing，分别检查 UI 和 raster；60Hz 的帧间隔约 16.7ms，120Hz 约 8.3ms。记录设备、构建模式、场景、样本量、分位耗时和长帧，不以模拟器 debug 流畅感或平均 FPS 代替。

重点场景是水位裁切与反色读数、日影蒙版、主题过渡、玻璃弹层及长记录列表。检查静止时无持续装饰帧、隐藏时 Ticker 停止，避免不必要的 saveLayer、全页模糊和重复语义。无法取得真机时明确保留该验证边界。

大历史数据检查初始化耗时、快照大小、同步序列化、统计查询与滚动开销；有测量依据再做索引、分页、缓存或存储拆分。验证方法见 [测试](testing.md)。

## 动效更新与事件时点

表盘 Ticker 只更新局部 DialFrame；数字按秒更新，静态资源子树与连续绘制分离。MotionGate 的渲染可见性用于停止 Ticker，实时 activeNow 判定用于一次性事件，防止多次状态提交合并到同一帧后误判来源。完成适配监听已接受的业务状态，帧投影到零不承担结算。

应用级未保存提示由 UnsavedStatus 唯一持有 AppPop 句柄，通过帧后复查协调展示/关闭。AppPop 的模态深度覆盖嵌套和实际 dismissed 生命周期；Toast 与状态浮层不计入模态深度，不停止业务计时。

## 第一阶段音频生命周期

flutter_soloud 4.1.7 与 audio_session 0.2.4 分别封装于 SoundPlayer，iOS 音频会话使用 ambient，混合其它音频并遵守静音开关，不增加后台音频模式。短音预加载，未就绪或初始化失败时直接跳过声音，不排队迟播；系统中断停止当前声音。应用非前台时停止声音并取消未触发的第二次强震；返回时先在静默状态校准业务，再建立新节拍基线。关闭声音总开关停止全部当前声音；关闭局部提示音只停止该来源的声音。关闭触感总开关取消待发的第二次强触；关闭局部触感只取消对应来源的第二次强触。系统触觉关闭时尊重系统设置，不由应用强行开启。播放器与监听随应用作用域释放。

### 第五阶段可见性规则

计时反馈增加当前模式门控：前台、专注根 Tab、对应栈页面及所选模式共同决定唯一允许的计时来源，事件发生时检查，不能依赖 mounted 或下一帧缓存。打卡 / 回顾 / 设置等非计时页没有允许的计时来源；所有计时声音与触感静默。本模式计圈面板仍允许该模式，通用设置 / 编辑 / 确认层静默，嵌套通用层覆盖计圈也静默。切换或隐藏立即停原来源声音并取消待发触感；再次可见先重建基线，不补播节拍或完成。

这不是把 `FeedbackService.foreground` 全局设为 false：它仍只表示应用生命周期，打卡、查看触感与显式试听保留各自规则。所有会话继续按真实时间校准与结算，是否允许反馈不影响进度或历史。后台通知独立按权限、开关和预约投影处理，不受前台模式选择限制。

站内状态条按 AppPop 模态深度挂起展示与触摸，最后一层实际 dismissed 后恢复最新状态；计圈面板同样隐藏状态条，不能把“仍允许计圈模式声触”误当作“状态条继续可见”。实现和回归范围见 [第五阶段](../plan/stage5-notifications.md)。

运行 / 暂停条持续展示，完成条只在原可见行自然到点时收满、短停留后自动退场，默认整体约 1200ms；超时或隐藏后不再补播。寿命计时使用单调展示基准且与会话 / 阶段绑定，重建或导航不重置；业务完成态仍保留在原模式，不能由展示超时调用结束 / 放弃。宿主、行、外壳与模态过渡支持中断，后台停装饰绘制，详见 [动效规格](../product/motion.md#第五阶段站内状态条)。

## 表盘调整与试听

DialAdjuster 仅持有局部草稿、采样和 Ticker，按下即接管；采样使用同一坐标变换，中心切换重置基准。惯性 / 收束总计最长 1200ms；模式 / 常用项 / 路由 / 后台中断先吸附提交，隐藏后无持续反馈。FocusActions 核对当前模式、会话、起始值及上限后接受命令；逐帧不保存。

设置完成音试听使用 FeedbackService.previewFinish，只检查前台、声音总开关及播放器可用性，不读取局部 scope、不触发震动。关闭声音总开关或进入后台立即停止试听；系统中断和释放沿用同一播放器生命周期。

## 本地通知的运行边界

开始 / 继续即预约固定结束锚点，主题、保存重试和重新对账不延后到点。暂停 / 结束 / 放弃 / 阶段转换取消原 pending，三模式不互相取消。习惯按本地日期、时刻与每日机会对账；前台到点读取最新事实并在静默提示前保存机会，同刻合并，模态中消耗但跳过。生命周期使用前台基线门控，ClockPulse 在回前台先刷新的顺序也不能补播隐藏期间的提醒或完成条。

后台总开关关闭仅取消 pending，保留 delivered；删除习惯清理两者，重置清理全部及元数据。串行对账携带代次，异步旧代完成后必须继续处理最新期望；重置等待当前平台操作完成再清理，失败可重试。截止占位先于系统调用保存，实际覆盖仅累计成功预约。系统预约不等于送达，Android 强制停止 / 厂商限制、iOS 专注模式 / 静音及长期不打开的有界队列都需用户真机验收。
