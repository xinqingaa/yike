# 一刻 UI 设计

本文规定页面构图、滚动边界与视觉要求；具体运动过程由 [动效规格](motion.md) 维护。动作改变什么数据由 [逻辑与交互](logic-and-interactions.md) 决定。具体尺寸、颜色、时长和曲线由 [Theme 与 Token](../engineering/theme.md) 维护。

## 页面结构与滚动

主要手机视口为 390 × 844。根页面共用外壳和固定底部导航，内容区占用剩余高度；根页面切换保留滚动及局部状态。安全区只占一次。面板的滚动、键盘避让、焦点和返回保持一致，打开面板后内容与操作仍可到达。

| 页面或面板 | 内容顺序与固定区 | 滚动边界与状态要求 |
| --- | --- | --- |
| 启动 | 已保存表盘的品牌静帧、名称、本机保存说明 | 准备完成进入专注，不人为延时；返回前台不重播启动 |
| 专注 | 日期/今日汇总、计时模式、表盘与读数、轮次或计圈、主次操作；固定根导航 | 常规内容按可用空间布局；窄屏保留滚动，长计圈列表单独滚动，不挤动表盘或遮挡操作 |
| 打卡 | 标题与今日进度、进行中习惯及本周标记、新建/已归档入口 | 列表主体滚动；名称进入详情，打卡按钮独立操作；空列表保留新建入口 |
| 习惯详情 | 返回与名称、周期次数、一年热力图、管理操作 | 主体滚动；编辑/归档/删除入口可达，不用热力图提供补卡 |
| 新建/编辑习惯 | 名称、图标、频率与周目标、提醒及时间、决策区 | 面板正文滚动，保存/取消区可达；键盘不遮挡字段和操作，错误贴近字段 |
| 回顾 | 周/月选择、周期导航、总计、每日图形、类型分布 | 主体滚动；翻期入口固定占位，返回当前周期的显示不推动正文；日期只显示主题按压反馈，不保留选中态；点击不改变图形高度 |
| 日期明细 | 标题/关闭、日期星期及合计、专注记录、习惯；底部前一天/后一天 | 只滚动正文，关闭和翻日始终可达；切日正文回到顶部，不改变来源滚动 |
| 设置 | 返回、三表盘预览、外观、计时配置、记录阈值、声音与震动、节拍间隔、重置 | 设置主体滚动；三表盘展示真实图形，偏好立即影响全应用，运行数字不跳变 |
| 常用倒计时分步面板 | 四槽列表或分秒编辑、可选步骤指示、操作区 | 指示器默认关闭，启用后在正文下方和操作区上方；稳定后自动保存，关闭面板留在设置页 |
| 确认与选择面板 | 当前值/操作后果、可选项、明确的主次动作 | 关闭或返回丢弃未确认草稿；危险动作显示后果，不靠 Toast 表达唯一结果 |

频率、外观和回顾范围使用仅选择条模式，不挂载空内容视口。计时模式只通过顶部 Tab 切换，确认期间保留原页面和选中项。根导航、页面栈与面板步骤各自承担导航职责，不为同一动作叠加多套跳转。页面隐藏可见滚动条，保留触摸、滚轮和键盘滚动。

## 专注布局、读数与量程

### 布局与读数

阅读顺序为日期与今日专注汇总、三个计时模式、表盘读数、轮次或计圈、主次操作、底部导航。表盘是主要视觉对象。番茄 / 倒计时待开始时可按秒拨动，详见 [统一时长规则](../plan/stage2-dial.md)。

开始、暂停、继续和完成沿同一主操作位置排列，使用最高强调的胶囊按钮。状态提示位于表盘附近，轻操作位于主操作下方。正计时运行时计圈与暂停并列且高度一致；计圈使用圈次、单圈、累计三列，数字右对齐与基线对齐，当前/暂停提示位于圈次列。长计圈列表独立滚动，不挤动表盘和主操作。倒计时常用项与编辑图标同行，移除自定义按钮；窄屏 / 大文字保持编辑入口可达，不挤动主操作。

| 内容 | 表达规则 |
| --- | --- |
| 运行读数 | 三种模式读数为分:秒，目标与正计时上限为 59:59；等宽数字，变化时不左右抖动 |
| 选项与再计标签 | 45秒、5分、1分30秒等，省略零单位 |
| 日期明细 | 显示实际有效秒数，整分钟不补零秒；与运行倒数向上取整的读数区分 |
| 今日已专注 | 只合计今天已入账的有效用时；正在运行但未入账的会话不提前算入 |

### 量程

| 模式 | 一圈的含义 | 显示与边界 |
| --- | --- | --- |
| 番茄专注、短休、长休 | 60 分钟；25 分钟约占 42% | 目标均不足一小时，不再新增“另有”分支 |
| 正计时 | 60 分钟，从空向满增长 | 最高 59:59，自动结束并保留完成态和计圈，不再回绕或显示“已满 N 小时” |
| 倒计时 | 始终为选中常用项时长 | 从调整到运行保持同一量程，开始不重新填满；中心读数为实际本次剩余时间 |

三套主题采用同一口径。机械番茄与正计时保留分钟数字刻度，倒计时使用无分钟数字的刻度，避免所选时长与刻度数字冲突。

### 每日图形与类型分布

周/月选择与周期日期导航分行排列。无记录时仍保留可浏览的日期框架；周图保留零值列，未来日期使用禁用状态，日期下方标注当日打卡次数。

周图根据真实每日分钟数绘制，量程至少 125 分钟，超出时扩展并明确标注。机械按 25 分钟块表达，水位为试管，日影为墨线软影；部分块及高度反映实际数据，不因显示为秒数而当作零记录。

月历为七列紧凑日期，按固定分钟分档，不随当月最大记录重新缩放：

| 档位 | 每日有效专注量 | 水位主题高度 |
| --- | --- | --- |
| 空 | 零记录或未来 | 空杯 |
| 低 | 大于零且不超过 30 分钟 | 杯内高度的 1/3 |
| 中 | 超过 30 且不超过 90 分钟 | 杯内高度的 1/2 |
| 高 | 超过 90 分钟 | 满杯 |

机械使用柿色圆形标记；水位使用圆形杯壁和水平水面，高度与颜色浓度分别表达，数字没有不透明底片；日影使用方形印框与靛蓝软影，档位越高，影子浓度与模糊越深。

今天通过图形上缘指针及加粗数字表达：机械短针、水位水滴、日影斜楔。日期点击不保留选中描边；按压时在图形上方绘制主题色反馈，机械/水位沿圆角或圆形、日影沿方形轮廓表达，键盘焦点单独表达。

类型分布只显示模式文字，名称和次数/时长位于同一行，下一行使用同宽轨道比较；文字长度不改变轨道长度。没有专注时不显示空的类型分布。

## 主题与视觉

三套主题共享页面结构、字体、业务与交互，表盘和配色作为一套选择。

| 主题 | 配色与材质 | 图形语言 |
| --- | --- | --- |
| 机械 | neutral 中性瓷白/石墨底，persimmon 柿色强调 | 清晰刻度与扇面；打孔、短条轮次、圆形日期 |
| 水位 | clear 中性清水玻璃，浅色石墨字、深色浅字，杯壁局部轻磨砂 | 水平水面与柔和反光；水滴轮次、小杯日期 |
| 日影 | 浅暖纸底与靛蓝，浅色背景 #EEEDE8；深色为墨灰 | 日晷软影与深色光晕；斜方轮次、方形印记 |

普通页面背景保持安静，强调色用于主操作、进度、今天与选中。根导航、局部切换和业务面板使用轻玻璃材质，避免重复叠套；降低透明度或不支持模糊时使用实色表面。危险操作有独立颜色和确认说明。

三种表盘保留完整物件比例和稳定位置，正计时不会缩成缩略图。计时数字使用等宽数字，长读数在中心安全区内，数字变化不左右抖动。普通图标为细线条，避免装饰性堆叠。

### 动效与反馈

运行图形按真实时间连续推进，暂停静止。变化位翻数、三主题节拍、完成与打卡的一次反馈、回顾过渡及所有中断/重播要求统一由 [动效规格](motion.md) 维护。减少动态效果保留正常读数与完整操作结果，直接呈现最终状态。

习惯详情的全年热力图使用可读的小方格、星期与月份定位，空间不足时横向滚动，初始显示最近日期。未打卡为空心框，完成为实心，当前归档期间为淡色；创建前、未来与范围外为极淡框。完成事实优先于归档外观。单位滚轮的数字自身在列内居中，单位独立紧靠右侧并略向下对齐，一至三列使用相同布局。时长统一使用两位数字和单字单位“时、分、秒”，次数保留“次/轮”；列内按最长候选值计算稳定宽度，窄屏或大字体时一致缩放，避免随数字切换左右跳动。

共享 Sheet 的左右留白由外壳统一提供，header 不叠加库默认的上下留白；正文与固定操作区只管理各自纵向间距。决策区默认不用分隔线，按钮保持清晰间隔。计时切换面板采用常规尺寸的“放弃”“结束”并列按钮，右上关闭、遮罩和返回均可取消。

## 图形与静态资源

三主题使用各自的表盘原稿与状态图层，保留原始比例和颜色。机械倒计时的专注过程图与普通机械图不同；暂停、休息等图层可以共用。水位的休息、水面与杯壁、日影的软影需分别表达，静态原稿与随时间变化的效果配合展示。

静态资源的来源、图层选择、颜色策略和 Flutter 落点见 [资源规范](../engineering/assets.md)。水位裁切、指针旋转与阴影变化仍需按会话进度实现，不能用一张静态图代替。

## 可访问性与文案

手机主要视口为 390 × 844，窄屏内容可滚动，不出现横向溢出。安全区只占用一次，内容不被底部导航或面板操作遮挡；键盘出现时字段和保存可达。页面隐藏滚动条，但保留触摸、滚轮和键盘滚动。

交互元素具备可读名称、充分触控区域和可见键盘焦点；表盘提供与数字一致的可读描述，水下重复读数不重复读屏。状态通过文字、形态和颜色共同表达，浅深模式保持清晰层级。

文案使用具体、简短、中性的说明，统计明确时间范围；不使用催促、评判或连续天数压力。放弃、删除、重置先说明结果再确认，打卡通过撤销恢复。

当前视觉与动效的实现、待决和验证状态见 [已知缺口](../known-gaps.md)；具体核验方法见 [测试与视觉验证](../engineering/testing.md)。

## 未保存状态层

未保存通过顶部安全区内的自定义浮层持续告知，不加入页面 Column 或压缩主体；可手动收起为“未保存”入口，再次展开和重试。窄屏及大文字允许提示和操作换行。业务面板与确认框优先，状态层暂挂起，表单保留就近失败与保存动作。关闭、恢复和部分成功行为见 [动效规格](motion.md)。

### 第一阶段反馈设置

“记录与反馈”显示声音总开关、触感总开关、试听提示音及原记录阈值；番茄钟、正计时、倒计时各组显示提示音、触感、每秒滴答及节拍间隔；打卡反馈独立显示提示音与触感。总开关关闭时对应局部开关置灰但保留选择；声音总开关或模式提示音关闭时，本模式每秒滴答置灰。节拍间隔面板提供关闭 / 1 / 5 / 10 / 15 分钟，选择立即保存，不增加确认按钮。

记圈表头按实际文本布局，列表视口服从剩余空间，避免字体测量与像素取整造成底部细小溢出；列表保持内部滚动，不接入后续阶段的记圈挂件或右侧面板。

## 时长选择器

专注、长休息和倒计时仅显示“分、秒”，短休息仅显示“秒”，不显示无用的小时或分钟列。分为 0 时秒列排除 0，必要时联动为 1；分大于 0 时允许秒为 0。保留滚轮稳定后自动保存与错误反馈。各场景范围和默认值见 [统一时长规则](../plan/stage2-dial.md)。

## 倒计时表盘与入口

机械倒计时始终使用无数字 plain 底图，番茄与正计时保留数字盘；切换常用项仅改量程，不切换底图。水位 / 日影沿用现有图层。首次进入高亮常用 1，读数与量程为该项时长；重复点击当前项保持读数和高亮，不支持取消选中。常用 1 编辑不显示清空按钮，其余三项可空。

常用项与编辑图标同行，移除自定义按钮；编辑进入完整设置页并自动展开常用项面板，关闭面板留在设置页。编辑后保留有效选中槽；所选槽清空回退常用 1；待开始读数超新上限则缩到上限。会话目标与量程保持不变。示例见 [第二阶段](../plan/stage2-dial.md)。

拨动时其它文案降低至 35%，主操作禁用至收束；轻触不改值，首次成功调整后隐藏本次进程的引导。表盘提供每次 1 秒的读屏增减。试听入口放在“记录与反馈”，声音总开关关闭时置灰，仅播当前主题完成音、不震动。
