# 一刻产品说明

## 产品定位与范围

一刻是本机使用的专注与习惯小工具：打开即可开始专注，一次点击完成今天的习惯，回顾时间和打卡的积累。面向工作、学习和日常习惯场景，整体安静、简洁，带有桌面计时器的实物感。

核心功能为三模式并行计时、表盘调时、计圈、习惯打卡、回顾统计、声音与触感、本地提醒、桌面组件及 iOS 实时活动。应用没有登录、云同步、社交、任务管理、排行榜、连续天数奖励或成就系统。

## 页面与导航

| 页面 | 主要内容 | 进入与返回 |
| --- | --- | --- |
| 专注 | 今日专注汇总、三种计时模式、表盘、轮次或计圈、主次操作 | 默认根页面；右上角进入设置 |
| 打卡 | 今日完成进度、进行中的习惯、本周标记、新建与已归档入口 | 根页面；习惯名称进入详情，打卡按钮独立操作 |
| 回顾 | 周/月范围、总计、每日图形、类型分布、日期明细 | 根页面；选择日期打开明细面板 |
| 统计 | 周/月概览、同期比较、趋势、类型环、开始时段、习惯与最近一年专注 | 从回顾标题进入独立页面，继承周期与筛选，返回保留原回顾状态 |
| 习惯详情 | 名称、本周/本月/最近一年次数、一年热力图、管理操作 | 从打卡页进入，返回打卡；归档或删除后回打卡 |
| 新建或编辑习惯 | 名称、图标、频率、提醒及校验 | 面板覆盖来源页面；新建保存回打卡，编辑保存回详情，取消返回来源 |
| 设置 | 外观、番茄钟、倒计时、声音、通用五类设置，含分类试听与重置 | 从专注进入，返回原专注状态 |

底部导航只有专注、打卡、回顾，使用图标和文字。正计时、倒计时是专注页内部模式，不占额外根页面。根页面内容区不另设跨根页面的主操作入口。

切换根页面保留本次打开期间的局部状态，包括回顾范围、选中日期和滚动位置；返回后显示同一份业务数据。打开详情、设置、编辑或日期明细不重建来源数据，也不停止正在运行的计时。

## 核心使用路径

打开专注，选择番茄钟、正计时或倒计时，开始后可暂停和继续；按当前模式结束或完成，符合规则的有效用时进入历史与回顾。三个模式可并行，切换只改变查看模式，不结束原会话；离开对应页面后以顶部半透明玻璃长进度条预览状态并可点击返回，每行提供至多一个暂停 / 继续操作。运行 / 暂停条持续展示，完成条拉满并显示小完成标记，短停留后自动退场，业务完成态仍可回原模式处理。交互细则见 [逻辑与交互](logic-and-interactions.md#切换计时模式)，呈现过程见 [动效](motion.md#站内状态条)。

在打卡页完成今天的习惯；点击习惯名称查看详情，也可新建、编辑、归档、恢复或删除。归档保留历史，删除移除该习惯及其打卡历史。撤销机会用于最近一次打卡操作，不构成长期历史编辑功能。

在回顾页查看周/月统计，打开具体日期核对专注与打卡事实；回顾只读。设置统一控制表盘、外观与计时偏好，修改设置不重写已经开始的会话或历史。

## 首次使用与产品边界

首次使用直接进入番茄钟第 1 轮待开始，没有专注或打卡历史；创建四个初始习惯。初始习惯只在首次初始化和确认重置后建立，用户删空后不补回。演示场景中的样例数据不属于用户的首次使用数据。完整初始值及配置范围统一见 [初始化](logic-and-interactions.md#首次使用与再次进入) 和 [设置](logic-and-interactions.md#设置流程)。

番茄专注、短休、长休和倒计时常用项均采用 1–3599 秒。番茄与倒计时待开始可拨动表盘，正计时从零计至 59:59 自动完成。倒计时首次选中常用 1、始终有选中项；编辑图标进入设置并展开常用项面板。

声音与触感使用总开关和各模式 / 打卡的独立配置，计时反馈只来自正在查看的模式。习惯提醒在前台显示静默短提示，在后台使用系统本地通知；设置中可查看实际预约覆盖范围。桌面组件展示专注与打卡进度，iOS 实时活动和动态岛提供计时预览及暂停 / 继续操作。提醒与外部动作的条件见 [逻辑与交互](logic-and-interactions.md#通知提醒)。

业务数据、保存和操作结果见 [逻辑与交互](logic-and-interactions.md)，页面构图、图形和动效见 [UI 设计](ui-design.md)。具体问题与测量边界见 [已知缺口](../known-gaps.md)。
