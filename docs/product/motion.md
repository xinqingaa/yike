# 动效规格

本页是 Flutter 动效的维护入口，依据本地产品与交互规则及 2026-10-23 用户批准的方案。日常实施不读取原型/Vue 源码；设计细节由 Flutter 运行结果与用户反馈迭代。业务结果见 [逻辑与交互](logic-and-interactions.md)，运行机制见 [运行时](../engineering/runtime.md)。

> 本页维护批准的目标规格。本轮已完成公共过渡、未保存自定义浮层与表盘更新隔离等六批接入；代码检查、原生过程及仍待测范围见 [实施记录](../reviews/2026-10-23-motion-implementation.md)，不将实现存在等同于全量视觉或真机性能通过。

## 原则与公共参数

一刻保持安静、实物感与低压力：时间变化持续可读，操作反馈短促，完成反馈一次收束。主操作不等待装饰动画结束，统计正文不翻数，历史图形不反复整组生长。视觉反馈沿用本页规则；第一阶段新增独立的声音和震动通道，矩阵见 [声音与震动](../plan/stage1-feedback.md)，系统通知仍待后续阶段。

时长/曲线读取 TS.motion：数字与轻反馈用 durationFast/easingStandard，布局切换用 durationNormal，主题及完成收束用 durationSlow；面板与模式沿用 durationSheet/durationTabViewport。幅度、图形比例与节拍窗口在本地类型化 YikeMotion 维护；页面不散落时长和曲线常量，生成主题不手改。

## 场景契约

| 场景 | 触发与过程 | 中断、结束与减少动态效果 |
| --- | --- | --- |
| 读数 | 仅变化位翻动；递增向上、递减向下，冒号静止；使用等宽稳定槽位 | 仅相邻一秒且同会话时翻动；跨小时、切换目标、后台恢复或大跨度用短淡入/直接定位；减少动态效果直接显示值 |
| 机械 | 同一有效时间推进扇面与指针；秒极轻反馈，分钟略明显 | 暂停冻结，完成一次收束；各模式最高 59:59，不再执行整小时回绕 |
| 水位 | 连续水平水面、轻反光与分钟涟漪；上下两份读数共用一份翻数相位，仅裁切和文字色不同 | 暂停/完成停止节拍；水下副本无独立读屏；恢复直接定位；减少动态效果关闭涟漪与装饰运动 |
| 日影 | 阴影随进度推进，秒明暗和分钟环保持微弱 | 暂停/完成静止；浅深模式材质连续；减少动态效果直接呈现当前进度 |
| 阶段完成 | 从未完成到完成且专注页可见时，按会话/阶段播放一次轻收束与文案过渡 | 不可见时只保留完成态，返回不补播；初始化、重建、主题切换和保存重试不播放；中断立即承接当前状态 |
| 主操作与模式 | 按压释放、稳定位置上的标签切换；第五阶段切换仅改变查看模式，选中面与内容同向过渡 | 不再因切换要求结束 / 放弃原会话；连续操作承接当前画面，显式结束 / 放弃仍保留各自确认，业务状态机独立保证幂等 |
| 打卡 | 每次新的有效打卡播放一次机械打孔、水位落滴或日影盖印；内存结果立即更新 | 取消/撤销短退场；撤销后新打卡可再播放；历史读取、返回和保存重试不播；保存失败仍明确显示未保存 |
| 计圈 | Sheet 内有效计圈从底部按钮区（暂停按钮附近）飞往读数区右缘挂件，主题小标记走向上拱起抛物线；durationSlow，落点缩放 1.12 回落 | 业务/可读计数立即更新；最多同时 3 个，多余直接更新；暂停不触发、不加落点震动；关闭、后台、上层模态和减少动态效果立即停止、不补播 |
| 习惯列表 | 新增、归档、恢复、删除仅过渡受影响项目 | 保留其它项目身份与滚动；取消不修改列表；减少动态效果直接更新 |
| 回顾翻期 | 日期与正文在裁切区域内水平翻页，不淡入淡出；周→月向前、月→周向后，上一期/下一期按时间方向，导航占位稳定 | 连续翻期以最新范围为准，反向承接当前位置；数据刷新不重播整图生长，选日不推动来源正文 |
| 日期明细 | 翻日正文短衔接并回顶部，关闭/翻日区固定 | 不改变来源滚动或图形高度；空日照常可达，边界与未来禁用不变 |
| 弹层与表单 | 使用共享打开/关闭与步骤过渡，错误贴近字段短出现 | 返回不提交；失败保留草稿；不使用强烈抖动或重复成功庆祝 |
| 主题与启动 | 同一业务进度下混合主题图层；冷启动准备后直接进入内容 | 不重置会话、表单或滚动；不增加品牌停留时间；减少动态效果直接呈现结果 |

## 一次性反馈与可见性

完成适配直接观察已接受的会话/阶段状态转换，实时判定播放资格，不依赖下一次 Widget build 的时点；同一帧隐藏、完成、返回也不补播。完成动画要求事件发生时应用在前台、专注根页选中、来源路由可见且当前模式面板可见。错过事件不排队；返回只显示完成态。打开其它页面不停止业务计时。

打卡动画表达本次有效内存操作，不表示落盘已经可靠成功。未保存状态及重试入口继续由应用边界呈现，重试不增加打卡事实或再次庆祝。一次性播放身份不写业务快照。

未保存提示是应用级自定义非阻塞浮层，不压缩正文；持续失败保持同一实例，可收起、展开和重试。Sheet/确认框等模态打开后挂起，直到最后一层实际 dismissed 后按最新错误恢复，表单保留就近失败说明。

运行中更换主题保留同一时间与事件进度；中途打开减少动态效果立即停止装饰并显示最终状态，重新关闭不补播刚停止的事件。暂停立即冻结进度和翻数，不拖到下一秒。

## 验证场景

检查 00:59/01:00、59:59 自动完成、倒数到零、暂停继续、再计及变更常用项量程。覆盖后台/路由/根 Tab 隐藏与恢复、动画中换主题/动态效果偏好、快速打卡撤销重做、保存失败重试和重建。

Widget 测试在确定时间点检查中间位移、同步裁切、静止和事件次数；持续动画不使用 pumpAndSettle 等待永远静止。原生检查正常/减少动态效果两组过程，检查滚动、焦点、文字缩放与性能。静态截图只证明对应静态状态，具体结果见 [已知缺口](../known-gaps.md)。

## 第一阶段声音与震动的边界

视觉完成收束仍要求专注页实时可见。第一阶段代码的声触只要求应用前台；第五阶段已确认改为仅当前查看且已启动模式允许计时声触，非计时页面静默；本模式计圈面板允许，通用模态静默，具体见 [前台反馈门控](../plan/stage5-notifications.md#前台计时反馈门控)。两个通道不等待动画结束或落盘成功，减少动态效果不关闭声音或震动。后台返回不补播，保存重试不重复反馈；第二阶段已接入表盘拨动；第三阶段已接入面板内计圈飞入，落点不加触感；回顾/统计查看卡使用选择触感，来源规则见 [逻辑与交互](logic-and-interactions.md#独立统计与查看反馈)。

## 第五阶段站内状态条（已确认目标，尚未实现）

运行 / 暂停持续展示，完成条短暂展示后自动退出；站内条寿命独立于业务完成态。一个玻璃容器容纳最多三行，行按模式固定顺序、按会话 / 阶段校验事件身份，不用每秒数字作为动画 key。

首版自然完成时序为 180ms 平滑收满进度并显现“已完成”小勾，完整状态停留 800ms，再以 220ms 淡出 / 向上收起，总体约 1200ms。参数集中维护，可按 UI 过程验收微调；不闪烁、不循环、不额外加声触。退场开始即移除交互和辅助语义；完成会话 / 短记录待处理仍在原模式，状态条超时不结算、不清理业务。

新增行约 240ms 展开 / 短距离淡入；暂停 / 继续约 160ms 仅过渡标签图标；行增减时同步玻璃外壳和顶部避让高度，邻行连续移动，未变化行不重播。多行同刻完成并行收起，不串成多次页面弹跳；最后一行退出时外壳同段收起。模式切换与条目集合更新同步，不先等条退完才导航，不做表盘到状态条飞行。

模态打开立即屏蔽点击与语义，约 160ms 随遮罩淡出后挂起；最后一层真实退场后按当前集合约 200ms 恢复。库 pause / resume 提供保活，不自行提供丝滑淡入淡出，需局部控制器承接；模态中断、快速切换、反向收展从当前画面继续，不重置其它行。后台停止装饰绘制。

只在当时可见的运行条自然完成时播放一次；隐藏 / 后台 / 模态期间完成不补播，当前模式完成也不新建一条通知。完成提示一旦隐藏或超时不因切换返回再次出现，仍可从专注模式 Tab 查看完成态。时限以单调展示时间维护，重建 / 换主题 / 保存重试不延长。减少动态效果时直接呈现满条和标记，保持短停留后直接移除，不移动 / 缩放 / 补间进度。完整情形与长期回归见 [第五阶段](../plan/stage5-notifications.md#状态条动效与寿命)。

## 表盘调时

机械 / 日影按角度、水位按位移，中心使用竖直位移。4px 后形成有效移动，快拨惯性、慢拨合法 5 分钟卡位、越界阻尼与整秒收束，最长 1200ms。减少动态效果直接定位。中断提交当前合法值，后台不恢复惯性。整秒 tick / 选择触感、整分钟 chime / 轻震按数值边界触发，不等待视觉收束；参数见 [第二阶段](../plan/stage2-dial.md#手感参数)。

## 回顾筛选与统计图形

进入统计或切换周期时，趋势、类型环和时段图在 durationNormal 内一次生长；筛选造成的柱高变化从旧值过渡到新值。同周期新增事实直接更新，不重新从零生长；统计内容滚出再回到视口时保留图表 State，不把滚动当成新进入。ChartValue 只管理局部呈现值，不拥有统计事实。日期月历仅局部档位衔接，选日与打开卡不改变图高。减少动态效果直接显示最终值。

记圈列表顶部的新行即时可见，浏览旧圈时保留滚动并提供“新增 N 圈，回到最新”。挂件为三主题共用的小玻璃计数胶囊，只有小标记保留主题形状。飞行标记不进入语义树；挂件数字即时反映已记完整圈数，不用动画到达作为计数依据。用户尚未完成真实设备对飞入效果的最终验收。
