# 动效规格

本页规定 Flutter 界面中的运动过程、事件身份、中断及减少动态效果。业务结果见 [逻辑与交互](logic-and-interactions.md)，执行机制见 [运行时](../engineering/runtime.md)。

## 原则与公共参数

一刻保持安静、实物感与低压力：时间变化持续可读，操作反馈短促，完成反馈一次收束。主操作不等待装饰动画结束，统计正文不翻数，历史图形不反复整组生长。视觉、声音和震动为独立通道，声音与触感矩阵见 [交互规则](logic-and-interactions.md#声音与震动)。

时长/曲线读取 TS.motion：数字与轻反馈用 durationFast/easingStandard，布局切换用 durationNormal，主题及完成收束用 durationSlow；面板与模式沿用 durationSheet/durationTabViewport。幅度、图形比例与节拍窗口在本地类型化 YikeMotion 维护；页面不散落时长和曲线常量，本地字重与统一字距的维护边界见 [主题](../engineering/theme.md)。

## 场景契约

| 场景 | 触发与过程 | 中断、结束与减少动态效果 |
| --- | --- | --- |
| 读数 | 仅变化位翻动；递增向上、递减向下，冒号静止；使用等宽稳定槽位 | 仅相邻一秒且同会话时翻动；跨小时、切换目标、后台恢复或大跨度用短淡入/直接定位；减少动态效果直接显示值 |
| 机械 | 同一有效时间推进扇面与指针；秒极轻反馈，分钟略明显 | 暂停冻结，完成一次收束；各模式最高 59:59，到上限保留完成状态 |
| 水位 | 连续水平水面、轻反光与分钟涟漪；上下两份读数共用一份翻数相位，仅裁切和文字色不同 | 暂停/完成停止节拍；水下副本无独立读屏；恢复直接定位；减少动态效果关闭涟漪与装饰运动 |
| 日影 | 阴影随进度推进，秒明暗和分钟环保持微弱 | 暂停/完成静止；浅深模式材质连续；减少动态效果直接呈现当前进度 |
| 阶段完成 | 从未完成到完成且专注页可见时，按会话/阶段播放一次轻收束与文案过渡 | 不可见时只保留完成态，返回不补播；初始化、重建、主题切换和保存重试不播放；中断立即承接当前状态 |
| 主操作与模式 | 按压释放、稳定位置上的标签切换；切换仅改变查看模式，选中面与内容同向过渡 | 原会话独立运行；连续操作承接当前画面，结束 / 放弃使用各自确认规则，业务状态机保证幂等 |
| 打卡 | 每次新的有效打卡播放一次机械打孔、水位落滴或日影盖印；内存结果立即更新 | 取消/撤销短退场；撤销后新打卡可再播放；历史读取、返回和保存重试不播；保存失败仍明确显示未保存 |
| 计圈 | Sheet 内有效计圈从底部按钮区（暂停按钮附近）飞往读数区右缘挂件，主题小标记走向上拱起抛物线；durationSlow，落点缩放 1.12 回落 | 业务/可读计数立即更新；最多同时 3 个，多余直接更新；暂停不触发、不加落点震动；关闭、后台、上层模态和减少动态效果立即停止、不补播 |
| 习惯列表 | 新增、归档、恢复、删除仅过渡受影响项目 | 保留其它项目身份与滚动；取消不修改列表；减少动态效果直接更新 |
| 回顾翻期 | 日期与正文在裁切区域内水平翻页，不淡入淡出；周→月向前、月→周向后，上一期/下一期按时间方向，导航占位稳定 | 连续翻期以最新范围为准，反向承接当前位置；数据刷新不重播整图生长，选日不推动来源正文 |
| 日期明细 | 翻日正文短衔接并回顶部，关闭/翻日区固定 | 不改变来源滚动或图形高度；空日照常可达，边界与未来禁用不变 |
| 弹层与表单 | 使用共享打开/关闭与步骤过渡，错误贴近字段短出现 | 返回不提交；失败保留草稿；不使用强烈抖动或重复成功庆祝 |
| 主题与启动 | 同一业务进度下混合主题图层与选择边框，以 easingGentle 衔接，快速反向切换承接当前混合状态；冷启动保留原生启动屏，准备后首帧直接展示内容 | 不重置会话、表单或滚动；不增加品牌停留时间；减少动态效果直接呈现结果 |

## 一次性反馈与可见性

完成适配直接观察已接受的会话/阶段状态转换，实时判定播放资格，不依赖下一次 Widget build 的时点；同一帧隐藏、完成、返回也不补播。完成动画要求事件发生时应用在前台、专注根页选中、来源路由可见且当前模式面板可见。错过事件不排队；返回只显示完成态。打开其它页面不停止业务计时。

打卡动画表达本次有效内存操作，不表示落盘已经可靠成功。未保存状态及重试入口继续由应用边界呈现，重试不增加打卡事实或再次庆祝。一次性播放身份不写业务快照。

未保存提示是应用级自定义非阻塞浮层，不压缩正文；持续失败保持同一实例，可收起、展开和重试。Sheet/确认框等模态打开后挂起，直到最后一层实际 dismissed 后按最新错误恢复，表单保留就近失败说明。

运行中更换主题保留同一时间与事件进度；中途打开减少动态效果立即停止装饰并显示最终状态，重新关闭不补播刚停止的事件。暂停立即冻结进度和翻数，不拖到下一秒。

## 验证场景

检查 00:59/01:00、59:59 自动完成、倒数到零、暂停继续、再计及变更常用项量程。覆盖后台/路由/根 Tab 隐藏与恢复、动画中换主题/动态效果偏好、快速打卡撤销重做、保存失败重试和重建。

Widget 测试在确定时间点检查中间位移、同步裁切、静止和事件次数；持续动画不使用 pumpAndSettle 等待永远静止。原生检查正常/减少动态效果两组过程，检查滚动、焦点、文字缩放与性能。静态截图只证明对应静态状态，具体结果见 [已知缺口](../known-gaps.md)。

## 声音与震动的边界

视觉完成收束仍要求专注页实时可见。计时声触仅当前查看且已启动模式允许计时声触，非计时页面静默；本模式计圈面板允许，通用模态静默，具体见 [前台反馈门控](logic-and-interactions.md#声音与震动)。两个通道不等待动画结束或落盘成功，减少动态效果不关闭声音或震动。后台返回不补播，保存重试不重复反馈；表盘拨动按数值边界反馈，计圈飞入落点不加触感；回顾/统计查看卡使用选择触感，来源规则见 [逻辑与交互](logic-and-interactions.md#独立统计与查看反馈)。

## 站内状态条

运行 / 暂停持续展示，完成条短暂展示后自动退出；站内条寿命独立于业务完成态。一个玻璃容器容纳最多三行，行按模式固定顺序、按会话 / 阶段校验事件身份，不用每秒数字作为动画 key。

自然到点时真实进度连续收满，显现完成文案与小勾，完整状态停留约 980ms，再以 220ms 淡出 / 向上收起，总体约 1200ms。参数集中维护，可按实际呈现效果调整；不闪烁、不循环、不额外加声触。退场开始即移除交互和辅助语义；完成会话 / 短记录待处理仍在原模式，状态条超时不结算、不清理业务。

新增行约 240ms 展开 / 短距离淡入；暂停 / 继续即时更新状态和图标；行增减时仅同步悬浮玻璃外壳高度，正文不移动，邻行连续移动，未变化行不重播。多行同刻完成并行收起，不串成多次页面弹跳；最后一行退出时外壳同段收起。模式切换与条目集合更新同步，不先等条退完才导航，不做表盘到状态条飞行。

悬浮条顶部保留紧凑细拖动条，整个浮层向上拖动时直接跟手收拢为顶部居中胶囊，释放约 260ms 收束，支持中断反向；点击 / 下滑展开，新增会话不自动展开。正文不参与收展动画，浮层外操作穿透。连续进度从会话锚点投影绘制，数字按秒变化；暂停冻结填充。扫光仅裁切在未完成轨道内：运行约 3 秒一轮、窄而柔和；暂停约 2.7 秒一轮、更宽更亮，不能误推真实进度。完成停止扫光、收满并短暂退场。收起 / 模态 / 后台停止光效，减少动态效果用静态进度与暂停高亮。

模态打开立即屏蔽点击与语义，约 160ms 随遮罩淡出后挂起；最后一层真实退场后按当前集合约 200ms 恢复。库 pause / resume 提供保活，不自行提供丝滑淡入淡出，需局部控制器承接；模态中断、快速切换、反向收展从当前画面继续，不重置其它行。后台停止装饰绘制。

只在当时可见的运行条自然完成时播放一次；隐藏 / 后台 / 模态期间完成不补播，当前模式完成也不新建一条通知。完成提示一旦隐藏或超时不因切换返回再次出现，仍可从专注模式 Tab 查看完成态。时限以单调展示时间维护，重建 / 换主题 / 保存重试不延长。减少动态效果时直接呈现满条和标记，保持短停留后直接移除，不移动 / 缩放 / 补间进度。长期回归见 [测试规范](../engineering/testing.md#并行通知与原生组件回归)。

## 设置导航与常用项

设置页分类导航随正文滚动吸顶，并与顶部栏共享连续的玻璃材质过渡：向下浏览时由内缩圆角逐渐扩展至全宽，返回顶部时反向恢复。分类导航固定五项等宽，标签始终单行，放不下时统一缩小文字；滚动、主题切换与大字号不改变导航的布局模式。分类选中随可见区块更新，点击分类平滑定位。常用倒计时在对应行内展开和收起滚轮，切换时保持单项展开；减少动态效果时直接呈现目标状态。

## 表盘调时

机械 / 日影按角度、水位按位移，中心使用竖直位移。4px 后形成有效移动，快拨惯性、慢拨合法 5 分钟卡位、越界阻尼与整秒收束，最长 1200ms。减少动态效果直接定位。中断提交当前合法值，后台不恢复惯性。整秒 tick / 选择触感、整分钟 chime / 轻震按数值边界触发，不等待视觉收束；参数见 [下表](#表盘手感参数)。

### 表盘手感参数

| 参数 | 当前参数 | 可感知结果 |
| --- | --- | --- |
| 中心区域位移 | 小于半径 20% 时改用竖直位移；上移增加；移动一个表盘直径为当前量程（60 分钟量程时等于 60 分钟）；切回角度采样时重置采样基准 | 中心附近不会因微小角度变化跳数，转换时读数连续 |
| 有效移动门槛 | 从按下点移动满 4 逻辑像素后才修改值；手势仍在按下即接管 | 轻触不改秒级时长，手抖不立即改值 |
| 惯性启动 | 以 60 分钟量程为基准：松手速度大于 6 分钟/秒，初速上限 120 分钟/秒；其它量程同比缩放，即 0.1 圈/秒启动、最多 2 圈/秒；`FrictionSimulation` drag 为 0.135 | 轻拨停住，快拨可继续转动，极快甩动有上限 |
| 慢速吸附 | 松手速度不超过 0.05 圈/秒（60 分钟量程时 3 分钟/秒），且距合法 5 分钟刻度不超过 1 分钟；其他情况取最近整秒；正好半秒向上取整；5 分钟卡位仅取当前上限内的 05:00–55:00，00:00 / 60:00 不参与 | 慢拨有明确的 5 分钟卡位，快拨不额外跳到 5 分钟 |
| 越界阻尼 | 以当前量程的 1/12 为尺度 k，越界显示量为 `d / (1 + abs(d) / k)`；60 分钟量程时 k=5 分钟 | 越界视觉空间逐渐收紧，最多接近当前量程的 1/12；实际提交仍在范围内 |
| 吸附 / 回弹 | 弹簧 mass=1、stiffness=300、damping=30；误差小于量程的 1/3000 且速度小于量程的 1/600 每秒时结束（60 分钟量程对应 0.02 分钟 / 0.1 分钟每秒）；惯性与收束总计最长 1200ms，超时直接到最终吸附值 | 收束时间有界，主按钮不会长期禁用 |
| 反馈节流 | 同一拨动过程声音与触感统一至少间隔 40ms；跳过的档位不排队补发；边界触感也遵守节流 | 快速转动不产生连续补播 |
| 音色与触感 | 直接复用当前主题 tick / chime 和 selection / light，声音不另作变调或音量分档 | 整分钟仅发分钟反馈，避免同一边界叠加 |

## 回顾筛选与统计图形

进入统计或切换周期时，趋势、类型环和时段图在 durationNormal 内一次生长；筛选造成的柱高变化从旧值过渡到新值。同周期新增事实直接更新，不重新从零生长；统计内容滚出再回到视口时保留图表 State，不把滚动当成新进入。ChartValue 只管理局部呈现值，不拥有统计事实。日期月历仅局部档位衔接，选日与打开卡不改变图高。减少动态效果直接显示最终值。

记圈列表顶部的新行即时可见，浏览旧圈时保留滚动并提供“新增 N 圈，回到最新”。挂件为三主题共用的小玻璃计数胶囊，只有小标记保留主题形状。飞行标记不进入语义树；挂件数字即时反映已记完整圈数，不用动画到达作为计数依据。
