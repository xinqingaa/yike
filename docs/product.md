# 一刻产品说明

## 产品定位与范围

一刻是本机使用的专注与习惯小工具：打开即可开始专注，一次点击完成今天的习惯，回顾时间和打卡的积累。面向工作、学习和日常习惯场景，整体安静、简洁，带有桌面计时器的实物感。

核心功能为番茄钟、正计时与计圈、倒计时、习惯打卡与管理、周月回顾和设置。应用没有登录、云同步、社交、任务管理、排行榜、连续天数奖励或成就系统。

## 页面与导航

| 页面 | 主要内容 | 进入与返回 |
| --- | --- | --- |
| 专注 | 今日专注汇总、三种计时模式、表盘、轮次或计圈、主次操作 | 默认根页面；右上角进入设置 |
| 打卡 | 今日完成进度、进行中的习惯、本周标记、新建与已归档入口 | 根页面；习惯名称进入详情，打卡按钮独立操作 |
| 回顾 | 周/月范围、总计、每日图形、类型分布、日期明细 | 根页面；选择日期打开明细面板 |
| 习惯详情 | 名称、本周/本月/最近一年次数、一年热力图、管理操作 | 从打卡页进入，返回打卡；归档或删除后回打卡 |
| 新建或编辑习惯 | 名称、图标、频率、提醒及校验 | 面板覆盖来源页面；新建保存回打卡，编辑保存回详情，取消返回来源 |
| 设置 | 表盘、外观、计时配置、阈值、提示音、重置 | 从专注进入，返回原专注状态 |

底部导航只有专注、打卡、回顾，使用图标和文字。正计时、倒计时是专注页内部模式，不占额外根页面。根页面内容区不另设跨根页面的主操作入口。

切换根页面保留本次打开期间的局部状态，包括回顾范围、选中日期和滚动位置；返回后显示同一份业务数据。打开详情、设置、编辑或日期明细不重建来源数据，也不停止正在运行的计时。

## 核心使用路径

打开专注，选择番茄钟、正计时或倒计时，开始后可暂停和继续；按当前模式结束或完成，符合规则的有效用时进入历史与回顾。专注期间可以使用其它页面，同一时间只保留一个计时会话。

在打卡页完成今天的习惯；点击习惯名称查看详情，也可新建、编辑、归档、恢复或删除。归档保留历史，删除移除该习惯及其打卡历史。撤销机会用于最近一次打卡操作，不构成长期历史编辑功能。

在回顾页查看周/月统计，打开具体日期核对专注与打卡事实；回顾只读。设置统一控制表盘、外观与计时偏好，修改设置不重写已经开始的会话或历史。

## 首次使用与产品边界

首次使用直接进入番茄钟第 1 轮待开始，没有专注或打卡历史；创建四个初始习惯。初始习惯只在首次初始化和确认重置后建立，用户删空后不补回。演示场景中的样例数据不属于用户的首次使用数据。完整初始值及配置范围统一见 [初始化](logic-and-interactions.md#首次使用与再次进入) 和 [设置](logic-and-interactions.md#设置流程)。

产品仅在本机保存。当前范围提供提示音与习惯提醒的配置和可见反馈，不接入实际音频、操作系统通知权限与调度，也不承诺系统后台持续执行。开关和完成反馈不改变计时、打卡或记录结果。

业务数据、保存和操作结果见 [逻辑与交互](logic-and-interactions.md)，页面构图、图形和动效见 [UI 设计](ui-design.md)。当前实现进度、已知偏差和待决事项见 [已知缺口](known-gaps.md)。
