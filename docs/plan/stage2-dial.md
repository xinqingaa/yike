# 第二阶段：秒级时长与表盘调时

状态：已实施，用户于 2026-10-24 真机验收通过；常用项、设置入口与试听按验收后确认的规则微调。返回 [计划索引](README.md)。本页保留最终范围和参数，不保留临时验收与交接过程。

## 有效时长

| 用途 | 入口与范围 | 默认值 |
| --- | --- | --- |
| 番茄专注（默认与本次） | 分秒，00:01–59:59 | 25:00 |
| 短休息 | 仅秒，1–59 秒 | 30 秒 |
| 长休息 | 分秒，00:01–59:59 | 15:00 |
| 倒计时常用项 | 分秒，00:01–59:59；常用 1 必填，其余三项可空；非空项不重复 | 03:00、05:00、10:00、20:00 |
| 倒计时本次目标 | 整秒，00:01 至当前选中常用项 | 首次进入取常用 1 |
| 正计时 | 从 00:00 累计至 59:59，表盘不调时 | 00:00 |

分为 0 时秒列只提供 1–59；分大于 0 时允许 0–59。从 01:00 将分调成 0，自动得到 00:01。滚轮稳定后自动保存，无额外确认按钮。运行倒数到零和正计时初始零合法，禁止的是零目标。正计时到上限自动结束，沿用记录规则，保留完成态与计圈，只发一次完成反馈。

## 表盘与本次草稿

仅番茄、倒计时待开始状态可拨；运行、暂停、休息、完成和正计时只读。机械与日影按角度，水位按竖直位移；中心区域用位移避免角度跳变。番茄一圈为 60 分钟，实际最大目标 59:59。

倒计时始终选中一个常用项：首次进入选择常用 1；点击其它项将本次值与量程设为该项时长；重复点击当前项保留读数与高亮。拨小读数仍保持选中。量程始终等于选中项，不存在取消选择后恢复 60 分钟的分支。机械倒计时始终使用现有 plain 无数字底图；番茄、正计时保留数字盘。水位与日影沿用现有图层，仅按相同规则改变比例。

从调整到运行保持同一量程，实际目标与量程在开始时冻结并随会话保存。例如选 5 分钟后调至 2 分钟，开始时为 40%，随后递减到零。修改偏好不影响已开始会话；“再计”沿用上一轮目标与量程、新建会话身份。

番茄拨动仅修改本次值，不改默认配置；开始后消费，下一轮用默认值。模式往返保留待开始的本次值；修改默认专注时长清除本次覆盖，其它设置不清除。草稿与常用项选中身份不持久化。

常用项与编辑图标同一行，移除自定义按钮。编辑图标通过 `/settings` 与 `SettingsRouteArguments` 进入完整设置页，首帧后自动打开常用倒计时 FlowSheet；关闭面板留在设置页，页面返回才回专注。编辑自动保存，未改动保持原状态；有改动时保留当前有效选中槽并更新量程，读数超新上限则缩到上限；所选槽被清空则回退常用 1。常用 1 不显示清空按钮，数据解析同样拒绝空值。

## 提交、反馈与中断

按下即接管手势，满 4px 才形成有效移动；轻触不改值。按实际秒值起算，普通吸附最近整秒，半秒向上；慢拨保留范围内合法的 5 分钟卡位，00:00、60:00 不参与。越界呈现阻尼并回弹，提交始终有效。

三主题拨过整秒为现有 tick＋选择触感；整分钟仅 chime＋轻震，不叠加秒反馈；上下限为一次中震。拖动与惯性均按数值经过触发，停住不持续反馈，至少间隔 40ms、不补播。只受本模式提示音 / 触感、总开关及系统允许控制，不受运行中每秒滴答或节拍间隔控制，不增加水位变调或额外音量档。

拨动中其它文案降至 35%，主操作禁用至收束；首次成功调整后结束本次进程内的引导。读屏增减每次 1 秒，复用相同提交校验。减少动态效果直接收束。切换模式、常用项、页面或后台前按当前值吸附提交；未有效移动保留原值。进入后台停止反馈，返回不恢复惯性。提交命令核对模式、无会话、起始值和上限，过期操作拒绝。

## 手感参数

| 参数 | 已确认初值 | 可感知结果 |
| --- | --- | --- |
| 中心区域位移 | 小于半径 20% 时改用竖直位移；上移增加；移动一个表盘直径为当前量程（60 分钟量程时等于 60 分钟）；切回角度采样时重置采样基准 | 中心附近不会因微小角度变化跳数，转换时读数连续 |
| 有效移动门槛 | 从按下点移动满 4 逻辑像素后才修改值；手势仍在按下即接管 | 轻触不改秒级时长，手抖不立即改值 |
| 惯性启动 | 以 60 分钟量程为基准：松手速度大于 6 分钟/秒，初速上限 120 分钟/秒；其它量程同比缩放，即 0.1 圈/秒启动、最多 2 圈/秒；`FrictionSimulation` drag 为 0.135 | 轻拨停住，快拨可继续转动，极快甩动有上限 |
| 慢速吸附 | 松手速度不超过 0.05 圈/秒（60 分钟量程时 3 分钟/秒），且距合法 5 分钟刻度不超过 1 分钟；其他情况取最近整秒；正好半秒向上取整；5 分钟卡位仅取当前上限内的 05:00–55:00，00:00 / 60:00 不参与 | 慢拨有明确的 5 分钟卡位，快拨不额外跳到 5 分钟 |
| 越界阻尼 | 以当前量程的 1/12 为尺度 k，越界显示量为 `d / (1 + abs(d) / k)`；60 分钟量程时 k=5 分钟 | 越界视觉空间逐渐收紧，最多接近当前量程的 1/12；实际提交仍在范围内 |
| 吸附 / 回弹 | 弹簧 mass=1、stiffness=300、damping=30；误差小于量程的 1/3000 且速度小于量程的 1/600 每秒时结束（60 分钟量程对应 0.02 分钟 / 0.1 分钟每秒）；惯性与收束总计最长 1200ms，超时直接到最终吸附值 | 收束时间有界，主按钮不会长期禁用 |
| 反馈节流 | 同一拨动过程声音与触感统一至少间隔 40ms；跳过的档位不排队补发；边界触感也遵守节流 | 快速转动不产生连续补播 |
| 音色与触感 | 直接复用当前主题 tick / chime 和 selection / light，不新增轻音量与水位变调 | 与用户已验收反馈保持一致；分钟替代同边界秒反馈 |


## 数据格式与工程落点

同一 `business_snapshot` 使用 schemaVersion 2，偏好采用 `focusSeconds` / `shortSeconds` / `longSeconds`，新会话按整秒与阶段范围校验；会话另外保存 `scaleSeconds`。用户明确无需旧数据兼容，不做迁移，不自动清除原数据；旧版、未知版或损坏数据保持读取阻断，由用户自行卸载或明确重置。

纯手感规则在 `focus/logic/dial_adjustment.dart`，局部手势与动画在 `focus/widgets/dial_adjuster.dart`，FocusActions 接受最终命令，FocusEngine / FocusProjection 统一计时上限。局部帧不写盘，内存接受与保存结果分开。
