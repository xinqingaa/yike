# 表盘调时与记圈

状态：表盘调时已有 [第二阶段执行计划](stage2-execution.md)，已按统一秒级时长修订，等待用户启动编码；记圈仍为后续阶段方案。返回 [计划索引](README.md)。声音与震动的具体取值见 [声音与震动](feedback.md)。

## 表盘调时

### 适用范围

| 状态 | 是否可以拨动 | 修改的对象 |
| --- | --- | --- |
| 番茄钟第 N 轮待开始 | 可以 | 下一轮的本次专注时长 |
| 倒计时待开始 | 可以 | 本次倒计时时长；选中常用项决定当前可调上限 |
| 正计时 | 不可以 | 从零累计，59:59 自动结束并保留完成态和计圈 |
| 运行、暂停、休息、完成 | 不可以 | 已经开始的会话目标保持固定 |

“本次”与“每次”的区别：设置中的专注时长是每轮的默认值；在表盘上拨动只改变下一轮，开始后固定到这次会话里，这次会话结束后，下一轮恢复设置中的默认值。在设置中修改专注时长时，会清除尚未开始的本次时长。本次时长只在本次打开期间有效，未开始的倒计时本次值与常用项选中身份同样不写入快照；会话开始后固定的目标和显示量程随会话保存。

目标时长统一按 [统一时长规则](duration-rules.md) 执行：番茄专注、常用倒计时设置为 00:01–59:59；倒计时未选中时也采用此范围，选中常用项后以该项时长为上限，短休息仅秒且为 1–59 秒，长休息为 00:01–59:59。分为 0 时秒只能选 1–59；从 01:00 将分拨成 0 时自动变成 00:01，禁止无效目标。

表盘按实际秒值起步，普通吸附到整秒，轻触不改值；慢速 5 分钟卡位仅取合法的 05:00–55:00。原整分钟取整、180 分钟范围和超限原值处理已被新规则替代。用户不要求兼容旧数据，可自行卸载或重置一次。

### 手势与主题映射

| 主题 | 手势 | 映射 |
| --- | --- | --- |
| 机械 | 绕表盘中心旋转，像拧发条 | 顺时针一圈映射当前量程：番茄或未选中倒计时为 60 分钟，选中倒计时为该常用项时长；连续角度采样与边界回弹避免跳值 |
| 水位 | 在杯身上下拖动 | 向上加水、向下放水；整杯高度映射当前量程，与机械同口径；目标上限由模式与选中项决定；继续上拉进入边界阻尼，不新增多杯或“另有” |
| 日影 | 绕盘面旋转，拨动影子 | 与机械相同的角度映射，影子跟随手指 |

手指按在表盘上会立即开始调时，不需要先等待滚动判断，所以在表盘区域内不会触发页面滚动。手指离中心太近（小于半径的 20%）时，角度变化不稳定，这时改按位移计算，避免数值突然跳动。

### 惯性、吸附与回弹

- 松手时如果手指还在快速移动，表盘会带着惯性继续转动并逐渐减速。惯性过程中每经过整秒 / 整分钟数值刻度，同样按最新矩阵产生拨动反馈，分钟处合并。
- 停下后吸附到最近的整秒。如果停下的速度很慢，而且离 5 分钟刻度不超过 1 分钟，会吸附到这个合法范围内的 5 分钟刻度（05:00–55:00），形成“咔”一下卡住的感觉。
- 超过 00:01 或当前可调上限时，有一段带阻尼的越界空间，松手后回弹到边界，越界时中震一次。
- 吸附结束后才提交新的时长。动画被打断（再次按下、切换模式、离开页面）时，提交当前的吸附结果，不丢失已经拨到的值。用户已确认进入后台同样立即按当前值吸附提交并停止动画 / 反馈，返回不恢复惯性、不补播；未有效移动则保留原值。

### 拖动时的界面

- 读数显示正在拨动的时长，三主题按同一量程实时跟随。番茄一圈 / 一杯 60 分钟；倒计时未选中时为 60 分钟，选中后为常用项时长。从调时、松手到运行保持同一量程，开始时不重新填满。机械倒计时始终使用无数字底图；具体例子和资源依据见 [表盘评估](stage2-dial-evaluation.md)。
- 表盘的说明文字改为“拨动调整”。表盘以外的文字，包括今日汇总、轮次说明和底部的次要操作，降到约 35% 的不透明度，主操作按钮暂时禁用。松手吸附后在 durationFast 内恢复。
- 待开始时，表盘说明文字的下方显示一行很淡的“拨动表盘调整本次时长”，用户第一次成功调整之后就不再显示（只在本次打开期间记住）。
- 减少动态效果时，没有惯性动画，直接吸附；声音和震动照常。

### 可访问性

表盘在可以拨动时作为“可调整”控件提供给读屏：名称为“本次专注时长”或“倒计时时长”，数值为当前时长，上滑或下滑每次增加或减少 1 秒。不可拨动时保持现有的只读描述。

### 倒计时常用项与编辑

初始 05:00 且不选中常用项，上限 59:59；选中项将读数与上限设为该项时长，允许随后拨动减小时长。再次点击取消选中，保留读数并恢复上限；不因数值相同自动高亮。

移除自定义按钮，编辑图标与常用项同行；进入仅管理常用倒计时的设置界面。实际编辑后返回取消选中、恢复上限并保留本次读数；没有改动则保持原状态。已开始会话不受常用项编辑影响。

## 记圈

### 列表与挂件

- 计圈列表固定显示可见行数：普通高度为当前圈加最近 2 圈，紧凑高度为当前圈加最近 1 圈。列表不再在这个小区域内滚动，新圈从顶部插入，最旧的一行被挤出可见区。
- 一旦有记录被挤出，在计圈区域的右侧边缘出现一个半露在屏幕边缘外的挂件，上面显示隐藏的圈数，例如“+3”。挂件从右侧滑入，暂停和继续时一直保留，会话结束后与列表一起移除。
- 挂件的主题外观：机械为金属吊牌加一枚柿色铆钉；水位为一滴水珠；日影为一张斜切的纸质书签。

### 抛物线飞入

每次计圈导致一行被挤出可见区时：

1. 被挤出的那一行原地收拢成一个小标记：机械为打孔圆点，水位为水滴，日影为斜方块。
2. 标记沿一条向上拱起的抛物线飞向挂件，用时 durationSlow，水平方向匀速，竖直方向先升后落。
3. 落到挂件上时，挂件轻微弹一下（放大到 1.12 后回落），隐藏圈数加一。计圈本身的轻震在按下时已经触发，落点不再额外震动。

连续快速计圈时，每一圈各自飞一个标记，最多同时存在 3 个，多出的直接加到计数上。减少动态效果或专注页不可见时不飞行，计数直接更新。计圈业务在按下时已经生效，不等待动画结束。

### 右侧记圈面板

点击挂件，或者点击列表区域，从右侧滑出记圈面板（复用现有 Sheet，方向为右侧，宽度约为屏幕的 86%）。面板打开时专注计时不受影响。

| 区域 | 内容 |
| --- | --- |
| 头部 | “全部计圈 · N 圈”与关闭按钮 |
| 实时读数 | 总计时与当前圈用时，随秒更新；暂停时显示“已暂停” |
| 统计 | 最快、最慢、平均单圈；不足 2 圈时不显示 |
| 列表 | 全部计圈，最新的在最上面，列为圈次、单圈、累计；最快一圈和最慢一圈分别用文字标签标出（不只靠颜色） |
| 底部操作 | “计圈”和“暂停/继续”，与专注页同一状态；暂停时“计圈”不可用 |

“结束并记录”和“取消计时”不放进面板，避免在长列表滚动中误触结束。会话被结束、取消或切换模式时，面板自动关闭。面板支持向右拖动关闭、点击遮罩关闭和系统返回。面板中计圈时，新的一行直接插入列表顶部，不播放飞入动画。

### 可访问性

挂件的读屏名称为“查看全部计圈，已隐藏 N 圈”。飞入动画不产生读屏内容。面板中的列表行按“第 N 圈，单圈……，累计……”读出。
