# 体验迭代计划：反馈、表盘调时、记圈与统计

状态：2026-10-24 第一阶段反馈配置修订与记圈修复已完成，待用户安卓 / iOS 双端验收；其余阶段仍待单独启动。确认后本目录是本轮唯一实施依据；实施中的变化回写本目录，完成后同步产品与工程规范。

## 收敛说明

此前动效相关内容分散在 [复审提案](../reviews/2026-10-23-motion-audit-and-polish-proposal.md)、[六批计划](../reviews/2026-10-23-motion-implementation-plan.md)、[实施记录](../reviews/2026-10-23-motion-implementation.md) 和 [页面精修指令](../decisions/2026-10-23-page-refinement.md)。这些文件保留为历史记录，本轮不再从中取任务。仍然有效的规则已在 [动效规格](../product/motion.md) 中维护：业务不等待动画、一次性事件按身份去重、减少动态效果时直接呈现结果。本轮新增内容只写在本目录。

本轮的反馈只有两个通道：**声音**和**震动**。视觉动画已经由现有动效体系负责，本轮只在新交互（表盘拨动、记圈飞入、统计图形）里补充必要的视觉过程，不另立“视觉反馈”类别。

## 已确认的取舍

2026-10-24 用户追加确认：保留声音与触感总开关；番茄 / 正计时 / 倒计时各自独立反馈设置，打卡独立；滴答与间隔同秒仅间隔；修复正计时记圈溢出。该修复不启动阶段 2–6。安卓与 iOS 真机由用户再次验收，之后移除临时脚本。

| 问题 | 结论 |
| --- | --- |
| 倒计时节拍 | 每秒播放主题滴答声；最后 10 秒每秒震动一次，到点时强震 |
| 番茄钟与正计时节拍 | 按间隔播放主题短音并轻震一次，番茄 / 正计时默认每 5 分钟、倒计时默认关闭，各模式独立选择关闭、1、5、10、15 分钟 |
| 周/月统计入口 | 新建独立的统计页；回顾页继续负责按日浏览 |
| 记圈全量面板 | 右侧 Sheet，面板内可以继续计圈、暂停和继续；“结束并记录”和“取消”只留在专注页 |
| 技术选型 | flutter_soloud 负责低延迟音效，Flutter 内置 HapticFeedback 负责震动，flutter_local_notifications 负责后续的后台提醒 |
| 主题声音 | 三个主题各一套音色，不提供额外的声音选择 |

## 实施阶段

第一阶段过程中仅按需定位问题，不逐项重复全量测试。阶段末集中运行一次 `node tool/verify.mjs`，并在 iOS 模拟器检查 UI；失败后仅复查受影响部分。声音听感与真机震动由用户最终验收，提供临时验收脚本，用户验收通过后移除临时文件。模拟器 UI 与程序调用检查不作为声音听感或真实震感通过的证据。

### 第一阶段执行清单

- [x] 用户确认：有效接受的动作立即反馈，不等待落盘；被拒绝的动作不反馈。
- [x] 用户确认：倒计时到零仅完成音与双强震，不叠加 tick / 轻震。
- [x] 用户确认：阶段末集中工程检查与模拟器 UI 检查，用户验收声音及震动。
- [x] 指定依赖、音频会话与 9 段仓库内合成音效。
- [x] 声音 / 震动服务、前后台门控及生命周期释放。
- [x] 总开关与三计时模式 / 打卡独立配置、旧快照迁移、设置即时保存与试听。
- [x] 开始 / 暂停 / 继续 / 计圈 / 打卡 / 撤销 / 完成事件。
- [x] 三种模式独立的每秒与间隔节拍，同秒合并、暂停和后台恢复不补播。
- [x] 正计时记圈溢出复现与修复，保持当前内部滚动结构。
- [x] 仅同步第一阶段涉及的规范及已知缺口。
- [x] 集中检查、临时验收脚本与用户验收交接。
- [ ] 用户确认声音听感及真机震动通过后，移除本次临时验收文件。

## 额外建议（不在本轮范围）

- 设置里的提示音一行加“试听”，播放当前主题的完成音，方便在三主题之间比较。
- 日期明细中把当日专注按开始时间排成时间线，与统计页的时段分布相互对应。
- 番茄完成时用灵动岛或实时活动展示剩余时间，与阶段 6 一并评估。
