# 第四阶段：回顾与统计

状态：已实现，等待用户 Android / iOS 真机验收；用户于 2026-10-24 确认与第三阶段合并实施；阶段 5、6 不启动。返回 [计划索引](README.md)。

回顾页和统计页的职责：回顾页按周/月浏览“每一天发生了什么”；新的统计页回答“这一段时间整体怎么样、有什么规律”。两页使用同一份记录和同一套计算口径（会话身份去重、跨日按日期分摊、秒精度），数字必须一致。

## 回顾页

### 类型筛选

底部“按类型”的三行提供筛选：

- 每一行可以点击。点击后筛选这个类型，再点一次取消。
- 筛选影响本页的专注汇总、专注次数或天数、周柱形图、月历以及日期明细中的专注记录。打卡与计时类型无关，始终显示全部。
- 被选中的行使用玻璃容器与主题强调色，名称和数值在行内垂直居中，轨道填满色更深；其余两行降低不透明度。汇总标题在原位变为“番茄钟专注”等，不插入顶部标签、不使用对勾；筛选到零数据时也不新增占位文案，保持图形位置稳定。
- 翻期、周月切换和离开再返回时都保留筛选。筛选期内该类型没有记录时，三行仍然显示，选中的行显示“0 次”，图形显示空状态。
- 切换筛选时，柱高和月历档位在 durationNormal 内过渡到新值。这里属于用户主动操作，不违反“数据刷新不重播整图”的规则。

### 图形的按压与长按

| 操作 | 结果 |
| --- | --- |
| 点击周柱或月历日期 | 打开该日期的 Menu 数据卡，与长按一致；通过卡内“查看当日记录”进入 Sheet |
| 长按周柱或月历日期 | 选择震动，并在这一项锚定弹出 Pop.menu 数据卡：日期与星期、一行专注时长与次数、一行打卡次数，最后一行“查看当日记录” |
| 按下 | 保持现有的主题按压反馈 |

未来日期不响应。数据卡跟随当前的类型筛选，并标明“仅番茄钟”等筛选说明。

### 入口

回顾页标题行右侧加一个“统计”图标按钮，位于“返回当前周期”的左边，进入统计页。进入时带上回顾页当前的周/月和周期。

## 习惯热力图

习惯详情热力图的查看规则：

- 点击或长按某一格：选择震动，并在这一格锚定弹出 Pop.menu 数据卡，内容为日期与星期、状态（已完成并显示打卡时间、未打卡、归档期间、创建前或范围外），以及这一周的完成次数“本周 2/3 次”或“本周 5/7 天”。
- 默认和卡片打开时都使用无边框实色块并铺满，按下用主题色轻反馈；由浅到深为创建前/未来、归档未完成、未打卡、完成。完成优先于归档。
- 只用来查看，不提供补卡。
- 数据卡显示期间，横向滚动热力图会关闭数据卡。

## 统计页

### 结构

从回顾页进入，路由为独立页面，返回时回到回顾页并保留回顾页原来的状态。

| 区域 | 内容 |
| --- | --- |
| 顶部 | 返回、“统计”标题；周/月切换；上一期、周期标题、下一期（与回顾页相同的规则：历史空期可以浏览，不能进入未来）；二级 Tab“全部 / 番茄钟 / 正计时 / 倒计时”，选中文字下方为小三角 |
| 概览 | 总专注、日均专注、专注天数、最长单次；与上一期的差值，例如“较上周 +1小时20分”，只陈述数字，不写“进步了”这类评价 |
| 趋势 | 周维度显示最近 8 周的每周总专注，月维度显示最近 6 个月；当前选中的周期高亮。点击某一柱，跳转到那个周期；长按显示数据卡 |
| 类型占比 | 环形图加图例，图例的每一行为类型、时长和百分比。点击环上的一段或图例行，等同于切换顶部的类型筛选；选中图例用带类型色的玻璃背景，色点、名称和数值垂直居中，不加对勾 |
| 时段分布 | 24 根小柱，按每次专注的开始时间所在的小时累计时长，标注“按开始时间统计”。显示一句陈述，例如“多在 21 点开始专注” |
| 习惯完成 | 每个进行中的习惯一行：本期完成次数与应完成次数（每天的习惯按本期已经过去的天数计算，每周习惯在周视图显示当前每周目标，月视图只显示完成次数与当前每周目标，不虚构月分母）、无边框色块表示每天的完成情况，点击和长按都查看该习惯的同一张 Menu 数据卡。不受类型筛选影响 |
| 最近一年专注 | 最近 365 天（含今天），每格一天，按每日专注量分四档，与月历的分档相同（0、不超过 30 分钟、不超过 90 分钟、超过 90 分钟）；点击和长按均显示同一张 Menu 数据卡，卡内入口进入每日记录 Sheet |

日均专注的分母：已经结束的周期按周期的总天数计算，当前周期按截至今天的天数计算，标明“截至今天”。没有记录的周期显示 0 和空图形，不显示“暂无数据”之外的空态插图。

### 三主题的个性化

统计页的结构在三个主题中完全一致，只调整图形的笔触，不另做三套页面。

| 图形 | 机械 | 水位 | 日影 |
| --- | --- | --- | --- |
| 趋势柱 | 与周柱相同的 25 分钟分块 | 试管水柱，圆角 | 墨线顶边加软影 |
| 类型环 | 方头分段，段间有刻度缝 | 圆头分段，带一道高光 | 渐变软影分段 |
| 时段小柱 | 实心短条 | 小水滴高度 | 斜切短条 |
| 年度热力图 | 无边框圆角色块 | 无边框圆角色块 | 无边框小圆角色块 |

进入统计页、切换周期时，图形一次性生长到位，用时 durationNormal；滚出屏幕再回到顶部保留 Tab 与图表状态、不重新生长；同一周期的数据刷新不重新生长；切换类型筛选时从旧值过渡到新值。减少动态效果时直接显示最终状态。

类型图配色在三主题间一致：浅色为珊瑚 `#C8735E`（番茄钟）、青绿 `#4C8E88`（正计时）、灰蓝 `#6A7FB8`（倒计时）；深色分别为 `#E8A08A`、`#87C2BA`、`#A5B7E4`。环与图例共用颜色，保留文字/百分比和选中容器。

### 可访问性

每个图形提供一句汇总描述，例如“最近 8 周专注时长，本周 6小时30分”，单个柱或格可以逐个读出。颜色之外，选中项同时使用文字或形状区分。

## 点击、长按与弹层

| 位置 | 点击 | 长按 |
| --- | --- | --- |
| 习惯详情热力图 | Menu 数据卡：日期/星期、完成状态、完成时间、当周进度 | 同一 Menu 数据卡 |
| 统计页习惯完成点 | 与习惯详情相同的 Menu 数据卡 | 同一 Menu 数据卡 |
| 最近一年专注 | Menu 数据卡：日期/星期、专注时长/次数、打卡次数、“查看当日记录” | 同一 Menu 数据卡 |
| 回顾周图／月历 | 同一类专注日期 Menu 数据卡，遵循当前类型筛选 | 同一 Menu 数据卡 |

四处均先查看 Menu 数据卡；专注日期只通过卡内“查看当日记录”进入同日 Sheet。习惯 Menu 仅查看，不提供补卡或跳转专注记录。

## 2026-10-24 已确认细则

- 页面从使用者角度保持简洁协调：短标签表达状态与范围，不在正文堆放规则说明。
- 回顾类型三行始终基于本期全部类型，可整行点击；有筛选时保留其它类型供切换，零数据也保留三行。筛选保留到翻期、周月切换和根 Tab 返回，打卡不受影响。
- 回顾图形点击和长按均打开同一张锚定数据卡，卡内入口进入每日记录 Sheet，松手保留；不做滑动扫日期。滚动、外部点击、翻期、切筛选时关闭。过去零记录可看，未来不响应。
- 数据卡宽约 260，窄屏受父约束；以完整可见为先，上下与左右交由统一库自动选择（固定上方模式不支持避边）；大字内容受菜单高度约束可滚动。每日记录仍为底部 Sheet，固定关闭与翻日，正文滚动并显示筛选标签。
- 习惯热力图点击和长按相同、单次操作只一次选择触感。默认、按压与卡显示期间不增加格子描边，查看状态只做轻微色彩强调；横向滚动关闭卡。每一格都不透明。真实日期格可解释创建前、归档和未来状态，创建前/未来不显示周进度；周对齐占位填最浅色且不响应，完成事实优先。
- 统计页固定返回与标题；其余配置/正文一起滚动，横向留白 24，区块以间距和分隔线组织，不层叠玻璃卡。概览为 2×2，依次总专注、日均、专注天数、最长单次。
- 进入统计带回顾周期与筛选，之后独立选择，返回保留原回顾状态。
- 当前周期与上一期同样已过自然日比较，均按日截至今天；上一期没有对应日期则到其月末，标明实际比较范围。完整历史周期比上一完整周期。
- 每日习惯按创建后、本期已过有效天数为分母；每周习惯月视图仅显示“本月完成 N 次 · 当前目标每周 X 次”。历史参考标明按当前规则，不还原不存在的历史目标版本。
- 类型环始终展示本期全部类型，选中类型突出，点击环或图例同步顶部筛选；其它专注指标随筛选。
- 趋势默认截至本期的最近 8 周/6 月。选择早于窗口时以该期为末端重建窗口；点击窗口内柱不移动窗口。周月切换重新确定窗口。
- 年度专注图始终截至今天最近 365 天，跟随类型筛选，独立于上方周期。按日点击/长按行为同回顾。
- 最长单次取同一会话在选定范围内的有效时长，标“最长单次（本期内）”；时段按本期分摊用时归到原会话开始小时，不带入范围外时长、不重复会话。
- 回顾/统计数据卡选择触感只受触感总开关及前台状态控制；习惯卡同时受打卡触感开关。不新增设置，不直接调用系统触感。
