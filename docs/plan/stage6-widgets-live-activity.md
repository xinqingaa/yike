# 第六阶段：桌面小部件与实时活动

状态：未启动，以下为后续草案。返回 [计划索引](README.md)。

## 范围

iOS 主屏 / 锁屏小部件与实时活动、动态岛，Android 桌面小部件；查看专注和打卡进度。暂不包含服务端推送更新、iPadOS 专项交互、macOS 小部件及 Android 动态取色。

## 产品设计

### iOS 小部件

**位置与尺寸**:

- **主屏幕**: Small (正方形)、Medium (横长)、Large (大)
- **锁屏**: Circular (圆形)、Rectangular (矩形条)、Inline (单行文字)

**内容**:

| 类型 | 内容 | 刷新 |
| --- | --- | --- |
| 专注进度 (Medium/Large) | 当前模式、轮次/圈数、倒计时/正计时、今日总时长 | 计时中每分钟,暂停/完成时立即 |
| 今日打卡 (Small/Medium) | 今日完成 N/M、进行中习惯列表（最多 3 个） | 打卡时立即 |
| 锁屏圆形 (Circular) | 今日打卡进度环形图,中心显示完成数 | 打卡时立即 |
| 锁屏矩形 (Rectangular) | 当前专注倒计时或"已暂停" | 计时中每分钟 |

点击小部件跳转到应用对应页面（专注或打卡）。

### iOS 实时活动（Live Activity）

**触发**: 开始番茄钟或倒计时时启动,暂停/完成时结束。正计时不启动（本阶段草案范围仅番茄与倒计时；正计时现已具有 59:59 上限）。

**锁屏样式**:

```
[图标] 番茄钟 第 2 轮
━━━━━━━━━━━━━━━━━━━━ 18:32
暂停  |  结束
```

**动态岛样式**:

- **Compact Leading**: 图标 + 轮次数字
- **Compact Trailing**: 倒计时 mm:ss
- **Expanded**: 模式名称、进度条、时间、两个按钮（暂停/结束）

**显示目标**：秒级倒计时；优先使用系统时间展示能力，具体刷新机制与平台限制在启动时核对，不承诺每秒跨端写入。

### Android 小部件

**尺寸**: 2x2 (小)、4x2 (中)、4x4 (大)

**内容**:

| 类型 | 内容 | 刷新 |
| --- | --- | --- |
| 专注进度 (4x2) | 模式、时间、开始/暂停按钮 | 计时中每分钟 |
| 今日打卡 (2x2) | 完成数 + 第一个习惯的图标和名称 | 打卡时立即 |
| 今日打卡 (4x2) | 完成进度条 + 前 3 个习惯列表 | 打卡时立即 |

点击小部件跳转到应用,点击按钮直接操作（开始/暂停）。

## 工程方向与启动边界

原方案拟手写 Swift / WidgetKit 实现 iOS 主屏及锁屏组件，评估 live_activities 与原生桥接实现实时活动和 Android RemoteViews。包版本、能力、系统最低要求、App Group、签名与后台限制在启动时核对；不在当前阶段添加依赖或扩展工程。

MMKV / AppPrefs 业务快照仍是唯一事实源。原生共享容器只保存展示投影，含会话身份、固定目标与量程、时间锚点、状态及今日汇总；原生按钮通过统一命令校验当前会话，不能直接写独立计时或打卡事实。主题共享内容须轻量，并支持数据缺失、未初始化或读取阻断。

三主题复用结构，按品牌色和材质调整；小尺寸保留时间 / 状态与清晰语义，不堆完整应用布局。点击进入对应根页，实时活动暂停 / 结束及 Android 开始 / 暂停的后台执行、短记录确认和权限边界须启动时确认。系统刷新预算与应用异常终止恢复不得形成两套计时口径。

实施顺序：确认平台版本、布局与操作边界；配置原生扩展与共享投影；接统一深链 / 命令；接会话和习惯更新；集中验证尺寸、锁屏 / 动态岛、暂停完成、数据失效及系统回收；由用户真机验收。模拟器结果不代替后台可靠性或耗电测量。
