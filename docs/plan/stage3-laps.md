## 已确认布局与交互

- 正计时页移除当前/最近圈列表和直接计圈按钮。待开始显示“开始计时”；运行/暂停保留主操作“暂停/继续”，下方“结束并记录 / 取消计时”。表盘下用轻量“计圈记录 · N 圈 ›”打开面板；完成态保留查看入口和主操作“完成”。开始不自动弹出面板，表盘保持原锚点，控制紧接入口，不为旧列表保留大块空白。
- 右侧 Sheet 宽为屏宽 100%，不另限宽，全高；内容避开安全区。左右留白 16（使用 TS），轻玻璃材质，三主题同布局。向右拖动、遮罩、系统返回只关闭面板。
- 固定头部“计圈 · 已记 N 圈”、关闭、总计时/当前圈、最快/平均/最慢、表头和底部操作；仅已记圈列表滚动，最新在前。当前圈不在列表重复。
- 运行态底部“计圈 / 暂停”，暂停态计圈置灰、显示“继续”；两态下方均为“结束并记录 / 取消计时”。取消需确认，短时结束沿用原确认；取消确认回原面板位置。打开确认不额外暂停。
- 顶部阅读列表时计圈直接显示新行；阅读旧圈时保留位置并显示“新增 N 圈，回到最新”。
- 最快/平均/最慢仅取手动记下的完整圈，满 2 圈显示；并列全部标记。59:59 自动完成保留面板与圈，最后一段标“末段 · 未计圈”，不加入圈统计；“完成”后清除当前会话。手动结束记录只保留专注总时长，不保留历史圈明细。

## 已确认飞入尝试

用户明确保留并先尝试效果：Sheet 内有效计圈时，小标记从底部按钮区（暂停按钮附近）沿向上拱起的抛物线飞向面板右缘挂件；暂停本身不计圈、不触发飞入。主页面保留暂停等会话操作，不放小圈列表或挂件。

- 挂件显示全部已记圈数，三主题统一为读数区右上方的完整玻璃胶囊“N 圈”，不再使用大尺寸或越出面板的造型；仅小标记分别为打孔圆点、水滴、斜方块。
- 飞行使用主题 durationSlow；落点放大到 1.12 回落，不额外震动。最多同时 3 个，多余直接更新。
- 业务与可读计数即时更新，不等动画。减少动态效果、后台、面板不可见或上层确认遮挡时直接更新，不补播；关闭/会话变化时取消飞行。
- 挂件用于计数，不增加第二个面板入口；装饰动画不产生读屏内容。
