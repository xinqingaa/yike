本计划依据 [统一时长规则](duration-rules.md)，细化 [表盘调时规格](focus-dial-and-laps.md#表盘调时) 与 [技术方案](technical-design.md)，只执行第二阶段。用户本轮授权变更计划，尚未授权编码。按下面的顺序推进；涉及未确认的边界、组合或手感参数时先问用户，不自行扩展。用户批准本计划后按清单连续实施，只有新增歧义或超出范围时再询问。

## 范围与已确认行为

| 项目 | 执行规则 |
| --- | --- |
| 可调状态 | 番茄钟第 N 轮待开始、倒计时待开始；正计时、运行、暂停、休息、完成均不可调 |
| 正计时 | 从 00:00 累计到最多 59:59，表盘不调时；到上限自动结束并按现有记录规则结算，保留完成态与计圈供查看，只发一次完成反馈；业务推进与展示均限制有效用时 |
| 番茄钟 | 默认与本次专注均为 1–3599 秒；设置使用分秒。新增内存中的本次值，开始时固定到会话并消费，下轮恢复默认；修改默认专注时长会清除未开始的本次值 |
| 休息 | 短休息只用秒，1–59 秒，默认 30 秒；长休息用分秒，1–3599 秒，默认 15 分钟。专注默认仍为 25 分钟 |
| 倒计时 | 初始 05:00、无选中项；未选中上限 59:59。选择常用项使读数和上限变成该项时长，再点取消时保留读数、恢复上限；移除自定义按钮，同行编辑图标仅进入常用项设置 |
| 有效时长 | 总时长必须大于 0；分为 0 时秒为 1–59，分大于 0 时秒可为 0–59；00:00 不可提交，零值选项联动见统一规则 |
| 表盘范围 | 番茄与未选常用项的倒计时为 00:01–59:59；选中项为倒计时当前上限。普通吸附到整秒，卡位只取当前合法范围，不能提交零或超限 |
| 含秒值 | 按实际秒数作为拖动起点，普通吸附四舍五入到整秒；仅按下未移动保留原值。慢速 5 分钟吸附优先，但只选择合法范围内的刻度 |
| 三主题 | 机械 / 日影旋转、水位上下拖动；番茄映射 60 分钟，倒计时始终无数字盘，量程与手势随选中上限变化，从调时到运行保持；具体见 [评估](stage2-dial-evaluation.md)。不新增多圈、多杯和“另有” |
| 反馈合并 | 用户最新确认：每经过整秒为已有 tick＋selection，每整分钟仅已有 chime＋轻震；停手不持续发声，快速经过仍 40ms 节流；替代原每分钟 / 每 5 分钟反馈方案 |
| 开关 | 受声音 / 触感总开关和本模式对应开关控制；“每秒滴答”“节拍间隔”仅管运行中的节拍，不控制拨动反馈 |
| 提交时机 | 拨动草稿逐帧呈现，吸附结束提交一次；再次按下、切换模式、离开页面时先提交当前吸附结果，按原模式归属提交，防止覆盖新模式 |
| 引导与可访问性 | 待开始说明“拨动调整”；首次成功调整后隐藏淡提示，只记本次打开；可调控件提供读屏每次增减 1 秒动作（跟随本次精度修订） |
| 减少动态效果 | 无惯性，直接吸附；保留按开关允许的声音与触感 |

不纳入记圈挂件、飞入和全量面板、统计页、后台通知、小部件，也不处理已记录的 17 处历史断链和 10 项旧测试失败。不增加依赖或存储 key。此次分钟改秒涉及存储格式变化，计划直接采用 schemaVersion 2，不兼容旧数据；撤销原计划“不改快照版本”的约束，不能把旧分钟字段直接解释成秒。

## 手感参数与边界

2026-10-24 用户确认的手感初值继续保留；最新确认的秒级范围与精度替代此前整分钟提交及 180 分钟范围。速度、角度和阻尼保留原意，倒计时变更量程时需按相同比例映射手势 / 惯性，避免仅视觉变化而灵敏度仍固定 60 分钟。后台中断规则保持。最后集中真机验收时，再根据用户反馈调整。

### 手感初值

| 参数 | 已确认初值 | 可感知结果 |
| --- | --- | --- |
| 中心区域位移 | 小于半径 20% 时改用竖直位移；上移增加；移动一个表盘直径为当前量程（60 分钟量程时等于 60 分钟）；切回角度采样时重置采样基准 | 中心附近不会因微小角度变化跳数，转换时读数连续 |
| 有效移动门槛 | 从按下点移动满 4 逻辑像素后才修改值；手势仍在按下即接管 | 轻触不改秒级时长，手抖不立即改值 |
| 惯性启动 | 以 60 分钟量程为基准：松手速度大于 6 分钟/秒，初速上限 120 分钟/秒；其它量程同比缩放，即 0.1 圈/秒启动、最多 2 圈/秒；`FrictionSimulation` drag 为 0.135 | 轻拨停住，快拨可继续转动，极快甩动有上限 |
| 慢速吸附 | 松手速度不超过 0.05 圈/秒（60 分钟量程时 3 分钟/秒），且距合法 5 分钟刻度不超过 1 分钟；其他情况取最近整秒；正好半秒向上取整；5 分钟卡位仅取当前上限内的 05:00–55:00，00:00 / 60:00 不参与 | 慢拨有明确的 5 分钟卡位，快拨不额外跳到 5 分钟 |
| 越界阻尼 | 以当前量程的 1/12 为尺度 k，越界显示量为 `d / (1 + abs(d) / k)`；60 分钟量程时 k=5 分钟 | 越界视觉空间逐渐收紧，最多接近当前量程的 1/12；实际提交仍在范围内 |
| 吸附 / 回弹 | 弹簧 mass=1、stiffness=300、damping=30；误差小于量程的 1/3000 且速度小于量程的 1/600 每秒时结束（60 分钟量程对应 0.02 分钟 / 0.1 分钟每秒）；惯性与收束总计最长 1200ms，超时直接到最终吸附值 | 收束时间有界，主按钮不会长期禁用 |
| 反馈节流 | 同一拨动过程声音与触感统一至少间隔 40ms；跳过的档位不排队补发；边界触感也遵守节流 | 快速转动不产生连续补播 |
| 音色与触感 | 直接复用当前主题 tick / chime 和 selection / light，不新增轻音量与水位变调 | 与用户已验收反馈保持一致；分钟替代同边界秒反馈 |

以上是交互调参，不是性能测量结论。最终手感与听感由用户真机验收；未经确认不改原生触感强度。若用户选择其它手感，先改本表再编码。

### 既有时长与生命周期边界

| 边界 | 已确认规则与影响 |
| --- | --- |
| 旧数据 | 用户自行卸载或明确重置，不做兼容或迁移；旧格式阻断读取、不自动覆盖；撤销旧超限值拨动分支 |
| 拨动中直接进入后台 | 视为中断，立即按当前值吸附提交并停止动画 / 反馈；返回不恢复惯性、不补播。未有效移动则保留原值 |

原规格已明确切换模式 / 离开页面提交值，因此未开始的番茄本次值在模式往返后继续保留，直到开始消费、修改默认值或应用进程结束；不另加持久化。若实现核对发现与现有模式切换规则冲突，先报告冲突再处理。
