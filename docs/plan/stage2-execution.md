本计划依据 [统一时长规则](duration-rules.md)，细化 [表盘调时规格](focus-dial-and-laps.md#表盘调时) 与 [技术方案](technical-design.md)，只执行第二阶段。用户本轮授权变更计划，尚未授权编码。按下面的顺序推进；涉及未确认的边界、组合或手感参数时先问用户，不自行扩展。用户批准本计划后按清单连续实施，只有新增歧义或超出范围时再询问。

## 范围与已确认行为

| 项目 | 执行规则 |
| --- | --- |
| 可调状态 | 番茄钟第 N 轮待开始、倒计时待开始；正计时、运行、暂停、休息、完成均不可调 |
| 番茄钟 | 默认与本次专注均为 1–3599 秒；设置使用分秒。新增内存中的本次值，开始时固定到会话并消费，下轮恢复默认；修改默认专注时长会清除未开始的本次值 |
| 休息 | 短休息只用秒，1–59 秒，默认 30 秒；长休息用分秒，1–3599 秒，默认 15 分钟。专注默认仍为 25 分钟 |
| 倒计时 | 复用当前 `countdown`，表盘、快捷项、自定义统一为 1–3599 秒，使用分秒；默认值与原有 3 / 5 / 10 / 20 分钟快捷项保持 |
| 有效时长 | 总时长必须大于 0；分为 0 时秒为 1–59，分大于 0 时秒可为 0–59；00:00 不可提交，零值选项联动见统一规则 |
| 表盘范围 | 番茄和倒计时统一 00:01–59:59，普通吸附到整秒，不能吸附到 00:00 或 60:00 |
| 含秒值 | 按实际秒数作为拖动起点，普通吸附四舍五入到整秒；仅按下未移动保留原值。慢速 5 分钟吸附优先，但只选择合法范围内的刻度 |
| 三主题 | 机械、日影顺时针一圈映射 60 分钟；水位上拉增加，一杯高度映射 60 分钟。实际目标上限 59:59，不再产生多圈、多杯和“另有”；跨 12 点连续采样用于防跳变并触发边界回弹 |
| 反馈合并 | 用户已确认：经过 5 分钟刻度只发轻音量 chime 与一次轻震，不叠加分钟 tick / selection |
| 开关 | 受声音 / 触感总开关和本模式对应开关控制；“每秒滴答”“节拍间隔”仅管运行中的节拍，不控制拨动反馈 |
| 提交时机 | 拨动草稿逐帧呈现，吸附结束提交一次；再次按下、切换模式、离开页面时先提交当前吸附结果，按原模式归属提交，防止覆盖新模式 |
| 引导与可访问性 | 待开始说明“拨动调整”；首次成功调整后隐藏淡提示，只记本次打开；可调控件提供读屏每次增减 1 秒动作（跟随本次精度修订） |
| 减少动态效果 | 无惯性，直接吸附；保留按开关允许的声音与触感 |

不纳入记圈挂件、飞入和全量面板、统计页、后台通知、小部件，也不处理已记录的 17 处历史断链和 10 项旧测试失败。不增加依赖或存储 key。此次分钟改秒涉及真实存储升级，计划显式增加 schemaVersion 2 迁移；撤销原计划“不改快照版本”的约束，不能把旧分钟字段直接解释成秒。

## 手感参数与边界

2026-10-24 用户确认的手感初值继续保留；最新确认的秒级范围与精度替代此前整分钟提交及 180 分钟范围。速度、角度和阻尼仍沿用原物理单位，音高映射改按新有效范围归一化。后台中断规则保持。最后集中真机验收时，再根据用户反馈调整。

### 手感初值

| 参数 | 已确认初值 | 可感知结果 |
| --- | --- | --- |
| 中心区域位移 | 小于半径 20% 时改用竖直位移；上移增加；移动一个表盘直径为 60 分钟；切回角度采样时重置采样基准 | 中心附近不会因微小角度变化跳数，转换时读数连续 |
| 有效移动门槛 | 从按下点移动满 4 逻辑像素后才修改值；手势仍在按下即接管 | 轻触不改秒级时长，手抖不立即改值 |
| 惯性启动 | 松手速度绝对值大于 6 分钟/秒；初始速度上限 120 分钟/秒；`FrictionSimulation` drag 为 0.135 | 轻拨停住，快拨可继续转动，极快甩动有上限 |
| 慢速吸附 | 松手速度不超过 3 分钟/秒，且距 5 分钟刻度不超过 1 分钟；其他情况取最近整秒；正好半秒向上取整；5 分钟卡位仅取 05:00–55:00，00:00 / 60:00 不参与 | 慢拨有明确的 5 分钟卡位，快拨不额外跳到 5 分钟 |
| 越界阻尼 | 以 5 分钟为归一化尺度，越界显示量为 `d / (1 + abs(d) / 5)`，单位为分钟 | 越界视觉空间逐渐收紧，最多接近 5 分钟；实际提交仍在范围内 |
| 吸附 / 回弹 | 弹簧 mass=1、stiffness=300、damping=30；位置误差小于 0.02 分钟且速度小于 0.1 分钟/秒时结束；惯性与收束总计最长 1200ms，超时直接到最终吸附值 | 收束时间有界，主按钮不会长期禁用 |
| 反馈节流 | 同一拨动过程声音与触感统一至少间隔 40ms；跳过的档位不排队补发；边界触感也遵守节流 | 快速转动不产生连续补播 |
| 轻音量与音高 | 5 分钟 chime 使用原音量的 35%；水位 tick 播放速率随总时长 1–3599 秒从 0.90 连续升至 1.15；其它主题速率 1.0 | 水位越高音调越高，全程连续变化；复用已有音源 |

以上是交互调参，不是性能测量结论。最终手感与听感由用户真机验收；未经确认不改原生触感强度。若用户选择其它手感，先改本表再编码。

### 既有时长与生命周期边界

| 边界 | 已确认规则与影响 |
| --- | --- |
| 既有超限数据 | 按统一时长规则的迁移方案处理，尚待用户确认；不再保留“首次拖动从 180 分钟起算”分支 |
| 拨动中直接进入后台 | 视为中断，立即按当前值吸附提交并停止动画 / 反馈；返回不恢复惯性、不补播。未有效移动则保留原值 |

原规格已明确切换模式 / 离开页面提交值，因此未开始的番茄本次值在模式往返后继续保留，直到开始消费、修改默认值或应用进程结束；不另加持久化。若实现核对发现与现有模式切换规则冲突，先报告冲突再处理。
