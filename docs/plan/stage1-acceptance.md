# 第一阶段临时测试验收脚本

当前验收版本包含：声音 / 触感总开关、三个计时模式与打卡独立反馈、同秒节拍合并、正计时记圈溢出修复。用户将在安卓与 iOS 真机再次验收。阶段 2–6 未启动。

## 正常应用启动

不需要运行测试脚本来“启用”声音或触感。重新启动当前正常应用即可使用实现，保留已有数据；不要通过卸载应用来刷新。

```bash
flutter devices
# 安卓正常应用
flutter run -d <安卓 device-id>
# 本机 iOS 构建使用用户目录中的 CMake；shell 配置见 README「运行」
PATH="$HOME/.local/opt/cmake-4.4.4-macos-universal/CMake.app/Contents/bin:$PATH" flutter run -d <iOS 真机 device-id>
```

安卓触感同时受系统设置控制。本次 Xiaomi 17 的系统记录已确认：系统触觉关闭时，一刻请求被 ignored_for_settings 拦截；随后只读复查系统开关已开启。Agent 未写入系统设置。若没有触感，先核对应用两级开关与系统触觉开关；触感强弱需要本人评价。

## 双端人工验收

安卓和 iOS 各完成一遍，出现问题时记录设备、模式、动作及当时开关即可。

| 步骤 | 操作 | 预期 |
| --- | --- | --- |
| 1 | 设置中查看“记录与反馈”、番茄钟、正计时、倒计时、打卡反馈 | 声音 / 触感总开关独立；三个模式各有提示音、触感、每秒滴答、节拍间隔；打卡有独立提示音和触感 |
| 2 | 正计时打开每秒滴答、间隔选 1 分钟；番茄每秒滴答关闭、间隔选 15 分钟；倒计时间隔选 10 分钟 | 只修改本组；关闭设置重开及重启应用均保留选择 |
| 3 | 关闭声音总开关，再开启 | 全部声音立即停；各组原选择保留，对应局部声音开关置灰；重新开启不把原本关闭的局部声音打开 |
| 4 | 关闭触感总开关，再开启 | 全部应用触感停止；各组原选择保留，重新开启不补触感 |
| 5 | 只关闭正计时声音 / 触感，开始、暂停、继续；再用倒计时或打卡 | 正计时遵循自己的配置；倒计时和打卡仍遵循各自配置 |
| 6 | 正计时开启声音、触感、每秒滴答，间隔 1 分钟，开始后切换底部 Tab | 每秒有 tick，第 0 分钟不发间隔；到 1 分钟仅 chime 和一次轻触，不叠加 tick |
| 7 | 倒计时设为 75 秒，开启滴答、间隔 1 分钟、声音与触感 | 第 60 秒仅间隔反馈；剩余 10–1 秒轻触；到零只有完成音与约 120ms 间隔的两次完成触感 |
| 8 | 倒计时关闭每秒滴答，保持触感开启，再用 15 秒倒计时 | 无 tick，最后 10 秒与完成触感保留；暂停不累计，不补播 |
| 9 | 番茄每秒滴答开 / 关，间隔设 1 分钟，开始并切到其它 Tab | 按番茄自己的配置反馈；暂停停止、继续从有效用时继续；不改正计时或倒计时配置 |
| 10 | 只关闭打卡提示音；打卡、取消、重做、撤销 | 打卡声被关闭，触感仍按打卡配置；取消与撤销只有选择触感；计时声音不受影响 |
| 11 | 三主题各在正计时连续计圈 15 次，暂停 / 继续，滚动圈次列表 | 没有黄黑溢出条或 RenderFlex 报错；圈次和累计正确，列表内部可滚动，主操作仍可达 |
| 12 | 手机文字调大后重复计圈 | 不溢出、文字可读、列表可滚动 |
| 13 | 倒计时运行中切后台，到点前或到点后返回 | 不补播错过的秒数 / 完成反馈；本阶段没有后台通知 |
| 14 | iOS 静音开关打开，或同时播放其它应用音乐 | iOS 音频遵守静音；正常混音不主动打断音乐；触感依系统允许与应用两级开关生效 |

当前仍使用系统触觉样式，安卓与 iOS 的实际震感不保证相同；本轮未擅自增强强度或绕过系统设置。

## 自动检查入口

```bash
# 隔离存储：迁移、模式隔离、两级开关、节拍、保存失败、后台恢复、记圈布局
node tool/stage1-acceptance.mjs unit
# iOS 模拟器：三主题 × 浅深、设置、节拍面板、记圈及真实音频预加载
PATH="$HOME/.local/opt/cmake-4.4.4-macos-universal/CMake.app/Contents/bin:$PATH" node tool/stage1-acceptance.mjs native <模拟器 device-id>
```

native 入口只用于模拟器 UI / 音频预加载，使用 FakeAppPrefs 和触感替身。它不会启用正常应用触感，不能证明真机震感；不要将它作为双端人工验收入口。截图在模拟器运行时复制到 `build/stage1/`。

集中检查结果见 [实施交接](stage1-handoff.md)。无需每次人工操作前重跑全套检查。历史断链与基线失败按用户决定本轮只记录。
