# 统一时长规则

日期：2026-10-24。状态：用户已确认，纳入 [第二阶段执行计划](stage2-execution.md)，尚未编码。本文替代本轮计划中旧的整分钟设置、整分钟提交和 180 分钟表盘上限。

## 范围、单位与默认值

| 用途 | 设置单位 | 有效范围 | 默认值 |
| --- | --- | --- | --- |
| 番茄专注（默认与本次） | 分、秒 | 00:01–59:59，即 1–3599 秒 | 25:00 |
| 短休息 | 仅秒 | 1–59 秒 | 30 秒 |
| 长休息 | 分、秒 | 00:01–59:59，即 1–3599 秒 | 15:00 |
| 倒计时（表盘与常用项） | 表盘按秒调整；常用项设置用分秒 | 未选常用项为 1–3599 秒；选中后上限为该项时长 | 初始 05:00，常用项均不选中；仍提供 03:00、05:00、10:00、20:00 |
| 正计时 | 从 00:00 向上累计；表盘不可调 | 累计最多 59:59 | 00:00 |

59:59 表示小于一小时，不包含 60:00。正计时从零累计、最多 59:59，不提供表盘调时；到上限自动结束，按现有记录规则结算，保留完成态与计圈且只发一次完成反馈，不允许继续累计。运行中剩余时间和完成态可以显示 00:00，本规则禁止的是无效的目标时长。

## 有效值与滚轮联动

- 总时长必须大于 0；分列为 0 时，秒列只提供 1–59。分列大于 0 时，秒列允许 0–59，05:00 是有效时长。
- 从 01:00 将分列拨到 0，秒值自动调整为 1，得到 00:01；有效值联动不产生一次 00:00 自动保存。
- 短休息只有秒列，不显示小时、分钟列；专注、长休和常用倒计时编辑只有分秒列，不显示小时列。
- 设置、按钮命令、表盘、常用项与序列化校验采用各场景同一套范围（倒计时表盘另受选中项上限约束）。UI 避免无效选项，业务仍拒绝越界、非整数或零目标。
- 保持设置现有的滚轮稳定后自动保存与保存失败反馈；不增加确认按钮。

## 表盘提交与边界

- 番茄与倒计时按实际秒值开始调整；普通吸附四舍五入到整秒，半秒向上。轻触但没有有效移动保留原值。
- 保留慢速 5 分钟卡位，但只使用当前范围内的 05:00、10:00……55:00。00:00 与 60:00 不作为吸附候选；没有满足条件的合法卡位时按整秒处理。
- 番茄与未选常用项的倒计时范围两端为 00:01 与 59:59；选中常用项后，倒计时上限为该项时长；越界草稿可呈现阻尼回弹，提交结果必须有效。边界不会收束到 00:00 或 60:00。
- 番茄一圈 / 一杯仍映射 60 分钟；倒计时的范围、刻度样式和调时到运行的比例关系见 [表盘评估](stage2-dial-evaluation.md)，已确认倒计时始终无数字盘，仅改量程，调时到运行保持一致。实际目标不足一小时，不新增多圈、多杯与“另有”。角度连续采样和边界回弹保留。
- 读屏增减跟随秒级步进，每次 1 秒；触摸与读屏共用同一校验与提交命令。
- 用户确认拨动反馈按经过的数值刻度触发：每整秒为已有主题 tick＋selection；每整分钟为已有主题 chime＋轻震，分钟处只发一组。拖动 / 惯性适用同一规则，手指停住不持续反馈，至少间隔 40ms，不排队补播。三主题均复用现有音色与系统触感，包括日影的秒档 tick。
- 拨动反馈只受本模式提示音 / 触感及对应总开关、系统允许控制，不受“每秒滴答”和运行节拍间隔控制。按最新“直接复用现在的声音和触感”目标，撤销原额外轻音量与水位变调扩展。慢速 5 分钟吸附是卡位规则，不再决定声音档位。后台中断、轻触保留与首次引导规则继续生效。

## 倒计时选择与编辑

- 首次进入未选中常用项，读数 05:00，上限 59:59；不因读数与“5 分钟”相同就自动高亮该项。
- 点击某常用项，将读数与可调上限设为该项时长；选中项保持高亮，即使之后拨动到更小的值。
- 再次点击同一项取消选中，读数不变，上限恢复 59:59；点击另一项切换读数与上限。不立即开始计时。
- 移除专注页“自定义”按钮，常用项与编辑图标同一行。编辑图标进入仅管理常用倒计时的设置界面，不修改本次草稿或其它设置。
- 表盘上下限、被选中项身份和本次目标是不同事实，不能通过时长相等反推选中；未选中身份是合法状态。本次选择不持久化为偏好。
- 常用项实际改动后返回取消选中，上限恢复 59:59、量程恢复 60 分钟，保留本次读数；未改动返回则保持原状态。已开始的会话始终不受影响。

## 数据格式与旧数据

用户明确：旧数据无需兼容，可以自行卸载或重置一次。第二阶段不实现旧数据迁移、旧快捷项去重或旧会话兼容分支，不自动卸载、重置或清除用户数据。

新时长偏好统一使用明确的秒字段 `focusSeconds`、`shortSeconds`、`longSeconds`，默认 1500 / 30 / 900。会话目标仍使用现有毫秒表示，但新建和读取目标均按新范围及整秒精度校验；倒计时实际目标与显示量程在开始时固定，显示量程随会话保存以支持重开恢复；番茄会话不再要求目标是整分钟。专注历史实际用时不因目标上限而裁切。

业务快照计划升级为 schemaVersion 2，保持原 `business_snapshot` key。仅接受新版本和完整新秒字段，未知 / 旧版本与损坏数据继续走现有读取阻断及用户明确重置入口，不把旧分钟值误读成秒，也不自动覆盖旧文件。本次仅更新计划；当前代码仍为版本 1。
