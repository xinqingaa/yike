# 第二阶段表盘交互与资源评估

日期：2026-10-24。状态：本页模式、反馈、底图和量程方案已由用户确认，尚未编码。执行入口见 [第二阶段计划](stage2-execution.md)，范围与默认值见 [统一时长规则](duration-rules.md)。

## 最终模式交互

| 模式 | 调时与运行 |
| --- | --- |
| 番茄钟 | 待开始可拨动 00:01–59:59，修改本次专注值；下一轮恢复设置默认。固定一圈 / 一杯为 60 分钟 |
| 正计时 | 从 00:00 累计，不可拨动调时；59:59 自动结束，按现有记录规则结算，保留完成态和计圈供查看，只发一次完成反馈，不允许继续累计 |
| 倒计时未选常用项 | 初始 05:00，无项高亮；目标范围 00:01–59:59，固定一圈 / 一杯为 60 分钟 |
| 倒计时选中常用项 | 点击将本次值和可调上限设为该项时长；一圈 / 一杯代表该时长。之后拨动可减小目标，常用项仍高亮；再次点同一项取消选中，保留目标、恢复 60 分钟量程 |

除正计时本身不可调外，运行、暂停、休息、完成状态均不可拨动。表盘草稿和动画不能改写已经开始的会话。未选中是独立状态，不从当前数值与常用项是否相等推导。

## 两套 SVG 对 Flutter 的实际影响

本次只查看本仓库映射、PNG 和绘制代码，没有访问外部 SVG 原稿或运行 DS 同步。导入 SVG 已转换为 PNG；底图中的刻度 / 数字是静态像素，指针、进度扇面、水位和阴影由 Flutter 动态呈现。

本地依据：

- `lib/theme/yike_artwork.dart` 中机械普通图通过 `session` 指向 plain 图；浅深各一组，共用进度 / 暂停 / 休息层。
- `lib/common/widgets/yike/dial.dart` 的 `_DialArtwork` 已在 `countdown` 模式选择 plain 图；该选择目前不依赖常用项是否高亮。
- 普通 `mechanical-light.png` 含 0、10、20、30、40、50 数字，`mechanical-light-plain.png` 保留大小刻度但没有分钟数字；已目视核对本地两张图。
- 水位和日影没有对应的第二套倒计时底图，分别复用现有水体 / 阴影图层，以 progress 驱动显示。

用户最终选择：**番茄与正计时保留数字机械盘；倒计时始终使用无数字机械盘，仅改变量程。** 选中、取消、拖动、开始不切换这两套机械底图；三主题浅深沿用各自现有资源。无需修改或新增 SVG / PNG，无需为每个常用项生成资源。

## 量程、进度与读数

必须分别维护本次目标、可调上限、图形量程和选中身份，不能继续用单个 `target` 同时代表这些值。

| 场景 | 中心读数 | 图形量程 | 进度示例 |
| --- | --- | --- | --- |
| 未选中，初次进入 | 05:00 | 60:00（实际可调上限 59:59） | 300 / 3600，约 8.33% |
| 选中“5 分钟” | 05:00 | 05:00 | 100% |
| 在该选中状态拨至 2 分钟 | 02:00 | 05:00 | 40% |
| 从上述状态开始 | 02:00 向下计时 | 仍为 05:00 | 从 40% 减到 0，不在开始时填满 |
| 待开始时取消选中，原值 2 分钟 | 仍为 02:00 | 恢复 60:00 | 120 / 3600，约 3.33% |
| 从未选中、2 分钟状态开始 | 02:00 向下计时 | 仍为 60:00 | 从约 3.33% 减到 0 |

改变选中状态时图形比例变化是新的量程所致；中心时长按选择 / 取消规则处理。读屏同时提供当前目标及范围，避免只靠环形面积理解数值。可调上限与图形量程要区分：59:59 有效而 60:00 不可作为目标。

秒级时长是事实源，图形按 `显示时长 / 当前图形量程` 投影。旋转一圈或竖直拖动一杯的手势增量也使用当前量程；中心位移回退、速度 / 惯性和吸附使用同一映射，防止视觉为 5 分钟而手势仍按 60 分钟计算。松手和开始均不临时切回另一量程。

开始时将实际目标和用于显示的量程固定到会话；固定量程随新会话保存并在重开后恢复，不能因返回页面或修改常用项突然改变。目标决定何时到点，量程只决定绘制和说明，不参与用时结算。

## 声音与触感

| 拨动经过的数值档位 | 声音 | 触感 |
| --- | --- | --- |
| 普通整秒，如 05:09 → 05:10 | 当前主题已有 tick | selection |
| 整分钟，如 05:59 → 06:00 | 当前主题已有 chime | light；同边界不叠加秒反馈 |
| 越界 | 无 | medium，每次越界一次 |

三主题采用同一档位规则，日影也复用自己的 tick。拖动与惯性按经过的数值触发，停住不按现实时间持续播放；40ms 节流，跳过的档位不排队补发。每分钟发声替代原每 5 分钟声音档位；慢速 5 分钟吸附仍保留，但不是另一组叠加音效。

声音与触感分别受总开关和本模式提示音 / 触感开关、系统允许共同控制；不受“每秒滴答”与运行中节拍间隔控制。直接复用现有音源、音量及系统触感，取消原水位变调和额外轻音量扩展。运行中的节拍继续遵守原设置，不因拨动规则变更而被强制开启。

## 常用项编辑入口

移除专注页自定义按钮。常用项与编辑图标同行，图标进入仅管理常用倒计时的设置界面，支持已有增改、清空和恢复默认；仍受统一分秒范围约束。全为空时保留编辑入口和可拨动表盘，初始目标不依赖非空常用项。

编辑页面复用 settings 的管理职责，经公开路由 / 参数进入，不由 focus 导入 settings 的私有 Widget。用户已确认：常用项实际发生改动后返回，取消当前选中，上限恢复 59:59、图形量程恢复 60 分钟，保留本次读数；未改动返回保持原状态。已经开始的会话始终使用冻结目标 / 量程。不在 build 中根据值相等自动选择。
