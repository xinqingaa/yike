# 小部件与实时活动

日期：2026-10-25。

中 / 大专注组件及一张汇总实时活动最多展示三模式，暂停保留；单模式尺寸优先运行中最近到点者，同时间用固定顺序，无运行态再选暂停态。外部最多暂停 / 继续，不提供开始、结束、放弃或打卡；统一进入主应用业务写入者。

Android 4×2 保留真实三模式紧凑列表，尺寸与布局按宿主宽高及实际条目数适配。习惯按打卡页顺序取前三项或首项，不因打卡换序；N/M 覆盖全部进行中习惯。

实时活动独立开关默认开启。全部自然完成后，从实际提交结束起请求锁屏静态结果保留约 5 分钟；主动清空立即移除。用户接受后台无执行机会时结构切换、完成文案及结束延迟，系统时间读数仍按能力推进封顶，不引入推送或第二套状态机。

iOS 锁屏 Inline 展示优先专注，Circular 显示打卡，Rectangular 显示优先专注。Android 锁屏保留既有到点提醒，不新增持续计时通知，不接入小米超级岛。

六阶段均已完成，具体尺寸、平台降级和协议由 [原生组件](../engineering/system-surfaces.md) 维护，布局见 [UI](../product/ui-design.md#android-桌面组件)。
