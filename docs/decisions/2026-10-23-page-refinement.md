# 页面精修原则

日期：2026-10-23。参考 Apple HIG 的布局、排版、动效、Sheet 和图表原则，并按用户选择转化为 Flutter 产品规则；不把具体像素或自动保存策略当作平台强制要求。

- 表盘和主操作保持稳定锚点，窄屏与大字优先可读、可滚动，不用裁切或屏蔽系统文字缩放解决拥挤。
- 机械主题正文 / 数字 Regular、标题 / 标签 Medium，物件感来自比例与刻度。用户明确批准直接调整机械主题现有字体 value，不另建排版覆盖层，也不启动外部 DS 同步；这是生成基线维护的特定例外。
- Sheet 默认按内容收缩，固定高度由具体调用声明；移除通用展开按钮和 75% / 全屏切换。通知设置等明确场景可固定高度。
- 偏好设置在有效选值稳定后自动保存；习惯等业务表单仍显式保存 / 取消。非法或未稳定草稿不提交，保存失败可重试。
- 回顾、统计和热力图强调同源数据、范围清楚、只读查看与中性文案。最终计圈入口、数据卡和热力图表达已由后续产品确认收敛。

当前布局与交互由 [UI](../product/ui-design.md)、[交互](../product/logic-and-interactions.md) 维护；弹层和字体实现见 [组件](../engineering/components.md) 与 [主题](../engineering/theme.md)。不再保留被后续规则替代的方案和验收流水。
