# 页面精修与 Apple 设计依据

日期：2026-10-23。以下保留前轮研究与取舍背景；最终实施范围以本节用户接管指令为准，先前提案不再作为实施授权。

## 用户接管后的最终指令

- Sheet 默认不传尺寸，短内容自行收起；需要固定高度时由该次调用传入 `maxHeight` 或 `height`。`fraction(1)` 会撑满接近全屏。删除展开按钮及 75%/100% 切换。
- 设置保留原有滚轮背景、常用倒计时与记录阈值的分步交互，仅去掉确认/保存/完成等提交按钮；有效选值落定即保存。清空、恢复默认仍执行原动作。
- 专注保留三模式共用布局和倒计时单行快捷项；正计时恢复原计圈表格与计圈按钮。
- 机械主题删除新增的排版覆盖层，直接修改机械主题对应 value：正文/数字 400，标题/标签 500。此改法已由用户单独确认，作为生成基线维护规则的本次明确例外，不修改外部 DS。
- 回顾恢复原柱状图、按类型统计与正文；周/月右侧依次为上一期、可点击日期、下一期，日期点击打开周期选择 Sheet，无下拉箭头。每日记录使用统一 maxHeight。
- 保留热力图及习惯 item，item 使用已有玻璃容器。
- 用户要求停止测试与自主设计，本次修订未运行测试、构建或模拟器验收；前轮测试结果不证明修订后的代码。

## 研究来源与适用方式

本轮直接查阅 Apple Human Interface Guidelines 的 Motion、Layout、Typography、Sheets、Charts，查阅日期为 2026-10-23。来源地址留作追溯，产品规则在本仓库自足维护：

```text
https://developer.apple.com/design/human-interface-guidelines/motion
https://developer.apple.com/design/human-interface-guidelines/layout
https://developer.apple.com/design/human-interface-guidelines/typography
https://developer.apple.com/design/human-interface-guidelines/sheets
https://developer.apple.com/design/human-interface-guidelines/charts
```

以下区分指南原则与一刻的产品判断。指南不是像素模板；不把自定义主题改成系统应用外观，也不把某一具体字号、字重、面板高度或自动保存策略归因于 Apple 强制要求。

## 布局：稳定、层次与渐进呈现

研究要点：按内容重要性组织界面，保持清晰对齐与一致布局，适配可用空间与文字尺寸；让辅助内容在需要时出现，避免主要任务被次要控制挤占。

一刻采用共同的专注布局骨架：日期/今日汇总、模式、表盘、辅助区、主要操作。同一主题和视口下三模式的表盘尺寸、中心与主要操作锚点一致；三主题仍保留自身比例。空间不足时三个模式共同进入紧凑布局，必要内容允许滚动，不能只缩小倒计时表盘。

四个常用倒计时为一行，自定义仅保留文字入口。长时长和大字允许横向浏览，不压缩到失去可读性或触控尺寸。计圈占用剩余空间，独立滚动并提供全部记录。打卡只滚动习惯列表，页首固定；星期状态放回对应卡片，取消脱离上下文的全局表头。

内容卡片采用安静的实体材质，玻璃保留给导航与操作层。减少边框、阴影和整宽分割线，使用留白分组；不是全局移除所有边界。高对比度与需要清晰操作范围时保留必要轮廓。

## 排版：可读性优先，主题感不依赖粗体

研究要点：用清晰的字号、字重和颜色建立层次；避免过细字形，支持 Dynamic Type 与系统辅助功能，不用装饰牺牲阅读。

机械主题的数字与正文采用 Regular，标题采用 Medium，取消快捷项额外加粗。机械感交给刻度、指针和比例，不能把水位主题的 Thin 照搬过来。前轮曾采用 Flutter 排版覆盖层；现按用户明确确认删除，直接调整机械主题的现有字体 value，不启动外部 DS 同步。

文字度量使用系统 TextScaler，容器随行盒增长；不以裁切、固定小高度或忽略字号缩放解决拥挤。保留系统粗体设置，数字等宽与逐位稳定布局继续生效。字重最终以原生字形检查，不凭 Widget 测量宣称视觉通过。

## 动效：表达关系，统一节奏与运动归属

研究要点：动效用于传达状态、空间和因果关系，应简短、可中断，并尊重减少动态效果。动画不是等待业务生效的条件，不重复播放装饰反馈。

回顾把周期标题与该周期的汇总/图形放在同一个翻期过渡中；周/月选择与前后控制是稳定导航，避免一部分翻页、一部分独立换场造成脱节。类型筛选只更新内容，不伪装成时间方向。减少动态效果直接展示最终状态。快速反向、连续翻期和维度切换仍保持正确数据与唯一可交互语义。

表盘变化只更新局部呈现；计时、打卡、落盘不等待动画完成。完成事件按业务身份去重，历史读取、返回和保存重试不补播。现有 [事件与重播决策](2026-10-23-motion-policy.md) 继续适用。

## Sheet：任务明确、按内容定高、直接操作

研究要点：Sheet 服务范围明确的任务，保持上下文；内容量与任务决定高度，需要时提供多个停靠点。指南不要求所有 Sheet 全屏，也不要求所有表单自动保存。

普通设置采用有效选值落定即保存，取消多余底部确认。滚轮滚动过程中只更新草稿，多列停止并吸附后合并提交，不逐刻度写盘。打开面板、空槽占位和默认选中本身不触发保存。零值、越界、重复常用项保留最后合法值，并就近显示错误；未落定/无效草稿关闭时丢弃。

常用倒计时一个约 75% 高度、可扩到安全区内全高的面板，点行内联展开滚轮，同一时间一项；清空与恢复默认靠近内容。其它简单设置使用内容高度。写入失败保留已接受的内存结果和重试，不把失败当校验拒绝，不重复业务提交。

每日长记录提供约 75% 与全高，固定标题/关闭/翻日，正文独立滚动。习惯编辑仍是独立保存的业务表单；重置仍需后果说明和明确确认。自动保存仅限已批准的偏好设置。

## 统计：先可读，再提供有意义的操作

研究要点：图表先表达主要信息，交互用于探索细节；视觉层次服务比较与理解，不能只靠颜色，也不必让所有文字都可点击。

回顾默认展示周/月总量，日期标题进入周期定位，类型筛选统一作用于汇总、图形和日专注记录。打卡独立统计，不随计时类型消失。周/月切换、翻期、返回保留筛选与浏览上下文；历史空期可浏览、未来不可进入。周期列表与主图使用同一派生统计口径，保留会话去重、跨日分摊和秒精度。

每日详情仍逐日移动，不跳过空日、不进未来、不跨打开时周期。分组标题保持静态，只有真正执行动作的元素具有按钮语义与按压反馈。

习惯热力图继续使用最近 365 天的二值完成事实。去掉每格边框，完成为主题填充，未完成为轻中性底，创建前/范围外留白，归档状态单独弱化；完成优先。一天最多一次，不制造“少—多”多级强度。提供文字图例与可访问说明，增加对比度时补充形状差异。

卡片内一格代表一天，七格是一周；周目标用“本周 X/Y 次”单独表达。星期格只读，不开放补卡，也不伪装成日期筛选器。

## 工程与验收取舍

保留现有业务引擎、单快照和 AppPop 边界，按实际职责拆分布局、偏好面板、周期查询，不建立万能页面基类或新状态框架。普通 Flutter 任务不读历史原型或改统一弹层依赖源码。

实施期间集中编码和自动化检查，完成后集中执行原生场景、目视与修复，避免反复打开模拟器打断实现。检查覆盖小屏/大字、浅深、三主题、减少动态效果、保存失败与中断。模拟器/debug 只证明相应功能和布局，不能替代真机性能或完整 VoiceOver 验收。

规范按职责归入产品、UI、动效、主题、组件和测试文档；过程评审收敛为交接结果，过时脚本与 build 临时产物清理，必要行为回归保留在对应功能测试中。
