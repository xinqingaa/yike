# 动效事件与重播策略

日期：2026-10-23。

完成反馈按会话 / 阶段身份仅在事件当时可见的专注页播放一次；返回、历史读取及保存重试不补播。新的有效打卡可播放，撤销后重做是新事件。

业务时间与局部绘制时间分离，动画不阻塞命令或保存，不代表持久化保证；中断和减少动态效果不改变业务结果。回顾周期采用裁切区域内的水平翻页，连续反向承接当前画面。

声音与触感后来接入为独立通道，受来源和可见性门控，不能套用过时的跨 Tab 计时反馈。完整规则由 [动效](../product/motion.md) 与 [声音与震动](../product/logic-and-interactions.md#声音与震动) 维护。
