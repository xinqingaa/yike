# 一刻 UI 与动效设计

整理日期：2026-10-22。承接 2026-10-16 已批准的产品基线；本文描述产品要求，不表示 Flutter 已完成实现。实际偏差和待决事项见 [已知缺口](known-gaps.md)。

本文拥有页面构图、滚动边界、视觉与动效要求；动作改变什么数据由 [逻辑与交互](logic-and-interactions.md) 决定。具体尺寸、颜色、时长和曲线使用当前 Theme/DS Token；这里不复制一份独立参数表。

## 页面结构与滚动

主要手机视口为 390 × 844。根页面共用外壳和固定底部导航，内容区占用剩余高度；根页面切换保留滚动及局部状态。安全区只占一次。面板由共享弹层管理滚动、键盘、焦点和返回，不在业务页面重写定位或拖拽机制。

| 页面或面板 | 内容顺序与固定区 | 滚动边界与状态要求 |
| --- | --- | --- |
| 启动 | 已保存表盘的品牌静帧、名称、本机保存说明 | 准备完成进入专注，不人为延时；返回前台不重播启动 |
| 专注 | 日期/今日汇总、计时模式、表盘与读数、轮次或计圈、主次操作；固定根导航 | 常规内容按可用空间布局；窄屏保留滚动，长计圈列表单独滚动，不挤动表盘或遮挡操作 |
| 打卡 | 标题与今日进度、进行中习惯及本周标记、新建/已归档入口 | 列表主体滚动；名称进入详情，打卡按钮独立操作；空列表保留新建入口 |
| 习惯详情 | 返回与名称、周期次数、一年热力图、管理操作 | 主体滚动；编辑/归档/删除入口可达，不用热力图提供补卡 |
| 新建/编辑习惯 | 名称、图标、频率与周目标、提醒及时间、决策区 | 面板正文滚动，保存/取消区可达；键盘不遮挡字段和操作，错误贴近字段 |
| 回顾 | 周/月选择、周期导航、总计、每日图形、类型分布 | 主体滚动；翻期入口固定占位，返回当前周期的显示不推动正文；选日不改变图形高度 |
| 日期明细 | 标题/关闭、日期星期及合计、专注记录、习惯；底部前一天/后一天 | 只滚动正文，关闭和翻日始终可达；切日正文回到顶部，不改变来源滚动 |
| 设置 | 返回、三表盘预览、外观、计时配置、记录阈值、提示音、重置 | 设置主体滚动；三表盘展示真实图形，偏好立即影响全应用，运行数字不跳变 |
| 常用倒计时分步面板 | 四槽列表或时分秒编辑、步骤指示、操作区 | 步骤指示在正文下方和操作区上方；保存单项返回列表，完成只关闭面板 |
| 确认与选择面板 | 当前值/操作后果、可选项、明确的主次动作 | 关闭或返回丢弃未确认草稿；危险动作显示后果，不靠 Toast 表达唯一结果 |

频率、外观和回顾范围使用仅选择条模式，不挂载空内容视口。根导航、页面栈与面板步骤各自承担导航职责，不为同一动作叠加多套跳转。页面隐藏可见滚动条，保留触摸、滚轮和键盘滚动。

## 专注布局、读数与量程

### 布局与读数

阅读顺序为日期与今日专注汇总、三个计时模式、表盘读数、轮次或计圈、主次操作、底部导航。表盘是主要视觉对象，不可拖动或点击设置时长。

开始、暂停、继续和完成沿同一主操作位置排列，使用最高强调的胶囊按钮。状态提示位于表盘附近，轻操作位于主操作下方。正计时运行时计圈与暂停并列，长计圈列表独立滚动，不挤动表盘和主操作。

| 内容 | 表达规则 |
| --- | --- |
| 运行读数 | 一小时内为分:秒，达到一小时后为时:分:秒；等宽数字，变化时不左右抖动 |
| 选项与再计标签 | 45秒、5分、1分30秒、1小时30分等，省略零单位 |
| 日期明细 | 显示实际有效秒数，整分钟不补零秒；与运行倒数向上取整的读数区分 |
| 今日已专注 | 只合计今天已入账的有效用时；正在运行但未入账的会话不提前算入 |

### 量程

| 模式 | 一圈的含义 | 超过一小时 |
| --- | --- | --- |
| 番茄专注、短休、长休 | 60 分钟；25 分钟约占 42% | 剩余超过 60 分钟时保持满圈，以“另有”说明多出的部分 |
| 正计时 | 60 分钟，从空到满，满圈后回绕 | 图形显示当前小时的比例，用“已满 N 小时”补充；整小时边界显示满圈 |
| 倒计时 | 本次所选的完整时长，从满到空 | 仍然是一圈，不按小时回绕；数字显示完整剩余时间 |

三套主题采用同一口径。机械番茄与正计时保留分钟数字刻度，倒计时使用无分钟数字的刻度，避免所选时长与刻度数字冲突。

### 每日图形与类型分布

周图根据真实每日分钟数绘制，量程至少 125 分钟，超出时扩展并明确标注。机械按 25 分钟块表达，水位为试管，日影为墨线软影；部分块及高度反映实际数据，不因显示为秒数而当作零记录。

月历为七列紧凑日期，按固定分钟分档，不随当月最大记录重新缩放：

| 档位 | 每日有效专注量 | 水位主题高度 |
| --- | --- | --- |
| 空 | 零记录或未来 | 空杯 |
| 低 | 大于零且不超过 30 分钟 | 杯内高度的 1/3 |
| 中 | 超过 30 且不超过 90 分钟 | 杯内高度的 1/2 |
| 高 | 超过 90 分钟 | 满杯 |

机械使用柿色圆形标记；水位使用圆形杯壁和水平水面，高度与颜色浓度分别表达，数字没有不透明底片；日影使用方形印框与靛蓝软影，档位越高，影子浓度与模糊越深。

今天通过图形上缘指针及加粗数字表达：机械短针、水位水滴、日影斜楔。选中描边沿原图形边缘，不盖住填充数据；键盘焦点单独表达。

类型分布只显示模式文字，名称和次数/时长位于同一行，下一行使用同宽轨道比较；文字长度不改变轨道长度。没有专注时不显示空的类型分布。

## 主题与视觉

三套主题共享页面结构、字体、业务与交互，表盘和配色作为一套选择。

| 主题 | 配色与材质 | 图形语言 |
| --- | --- | --- |
| 机械 | neutral 中性瓷白/石墨底，persimmon 柿色强调 | 清晰刻度与扇面；打孔、短条轮次、圆形日期 |
| 水位 | clear 中性清水玻璃，浅色石墨字、深色浅字，杯壁局部轻磨砂 | 水平水面与柔和反光；水滴轮次、小杯日期 |
| 日影 | 浅暖纸底与靛蓝，浅色背景 #EEEDE8；深色为墨灰 | 日晷软影与深色光晕；斜方轮次、方形印记 |

普通页面背景保持安静，强调色用于主操作、进度、今天与选中。根导航、局部切换和业务面板使用轻玻璃材质，避免重复叠套；降低透明度或不支持模糊时使用实色表面。危险操作有独立颜色和确认说明。

三种表盘保留完整物件比例和稳定位置，正计时不会缩成缩略图。计时数字使用等宽数字，长读数在中心安全区内，数字变化不左右抖动。普通图标为细线条，避免装饰性堆叠。

### 动效与反馈

运行图形按真实时间连续更新，保留每秒轻反馈、每分钟略重反馈和阶段结束的一次完成反馈；暂停静止。主读数只对变化位逐位翻动，递增向上、递减向下，冒号静止；后台恢复或大跨度变化短过渡到当前值，不补播秒数。水面上下两份读数同步。

按钮有按压、释放和标签过渡；模式切换保留方向连续的选中与内容过渡。打卡分别使用打孔、水滴或盖印的一次反馈。回顾翻期的日期与图形同向衔接，柱形不反复整组生长。普通正文和统计数字不逐位翻动。

减少动态效果时直接呈现最终状态，数字继续按时间更新，操作结果完整。

## 动效行为矩阵

动效表达当前业务状态，不作为业务完成、保存或结算的触发依据。显示动画被中断、减少或关闭时，业务结果必须一致。

| 场景 | 触发与过程 | 结束、中断及重播 |
| --- | --- | --- |
| 计时数字 | 只翻动变化位；递增向上、递减向下；冒号静止；短过渡使用 motion.duration-short 与 motion.easing-standard | 暂停停止更新；后台恢复或大跨度变化直接短过渡到当前值，不补播漏掉的秒数；普通统计不逐位翻动 |
| 机械表盘 | 按同一有效时间推进扇面与指针，秒轻反馈、分钟较重反馈；倒计时使用无数字专注图 | 暂停静止；到点只完成当前阶段；状态图层与进度裁切分别表达，不重绘静态原稿 |
| 水位表盘 | 水位连续变化，表面轻反光、分钟涟漪；上下两份数字同一时刻更新 | 暂停停止时间反馈；上下读数裁切和反色一致，重复副本不重复读屏 |
| 日影表盘 | 阴影按进度改变，秒明暗、分钟环；浅深模式保持对应材质 | 暂停/完成/休息有独立外观，恢复直接定位真实进度 |
| 阶段完成 | 当前阶段到点时一次完成反馈和文案过渡 | 等待用户不反复结算；重开和普通返回不重复产生完成记录；是否重播视觉反馈若无明确 Evidence 则保持未验证 |
| 主操作与模式选择 | 按压、释放、标签过渡；模式选中面和内容方向连续 | 动画中连续点击仍遵守状态机和防重复规则；确认取消不提前切换业务模式 |
| 打卡 | 成功操作一次打孔、水滴或盖印反馈 | 取消、撤销、重进页面不得制造新的打卡事实；返回重播与中断细节未验证时明确记录 |
| 回顾 | 前后翻期的日期与图形同向衔接，周/月切换平稳 | 不因每次重渲染而整组柱形重新生长；选日、切日和关闭明细不推动来源正文 |
| 根导航与详情 | 根内容即时切换并保留状态；底部选中面连续反馈；详情和返回使用共享页面转场 | 区分根页面与页面栈；返回恢复原焦点和滚动，不重新初始化数据 |
| 面板与分步选择 | 共享打开/关闭和步骤前进返回，正文与固定决策区保持稳定 | 返回不等于保存；关闭丢弃当前未提交草稿，保留之前已经保存的单项 |
| 减少动态效果 | 直接显示最终状态，保留正常读数和操作反馈 | 功能、保存和结果不减少；减少动态效果的静态采集不能证明正常动画过程 |

公共时长、曲线、按压比例和页面转场由 [Theme](theme.md) 与 [组件](components.md) 拥有；表盘状态由当前进度、tone、scale 与资源图层驱动，不从截图反推 SVG 绘图路径。跨平台材质与转场近似需在实现验收中说明。

## 组件、Token 与静态资源

Flutter 使用 `lib/common/` 的公共组件、`AppPop` 弹层和上下文 `TS`，对应关系查 [组件](components.md)、[目标适配](proto-bridge.md) 与 [Theme](theme.md)。公共能力不存在时记录缺口，不能在 feature 复制另一套导航、弹层或主题。具体业务组合仍属于 feature，源 Evidence Region 不等于 Widget 或文件边界。

SVG 在 PBWork DS 唯一维护，Flutter 消费已同步 PNG。图标查 `proto-bridge.icons.json` 与生成的 CommonIconName，主题图形查 `proto-bridge.themes.json.artwork`；由元数据选择实际文件、默认图、sessionAsset、layerAsset 和各 view，不按文件名猜路径，也不从截图重绘已同步资源。intrinsic 图形保留原色，theme 单色图标才跟随主题。资源目录和倍率规则见 [资源规范](assets.md)。

机械倒计时的专注过程图与普通机械图不同，但暂停/休息等层可由 layerAsset 共用。水位的 rest/wave/glass、日影的 shadow 是独立命名视图；静态资源同步不包含水位裁切、指针旋转或阴影变化的业务动画。

采集保留图形身份、摘要、实际图层引用、几何和截图，资源本体走 DS 同步。当前正常采集压制动态效果，因此此文中的动效要求属于设计说明，尚不能标为真实过程采集已通过。

## 可访问性与文案

手机主要视口为 390 × 844，窄屏内容可滚动，不出现横向溢出。安全区只占用一次，内容不被底部导航或面板操作遮挡；键盘出现时字段和保存可达。页面隐藏滚动条，但保留触摸、滚轮和键盘滚动。

交互元素具备可读名称、充分触控区域和可见键盘焦点；表盘提供与数字一致的可读描述，水下重复读数不重复读屏。状态通过文字、形态和颜色共同表达，浅深模式保持清晰层级。

文案使用具体、简短、中性的说明，统计明确时间范围；不使用催促、评判或连续天数压力。放弃、删除、重置先说明结果再确认，打卡通过撤销恢复。

## 验证方式

按 [测试规范](testing.md) 在相同移动视口进入固定 Case，检查结构、组件、Token、状态与交互。动效需在正常运动偏好与减少动态效果下分别演练；静态截图或参数相同都不能单独证明真实过程一致。未实现 Flutter 业务页面前不声明移动视觉或动效验收通过。
