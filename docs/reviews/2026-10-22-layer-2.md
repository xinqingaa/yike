## 实现

`features/local_data` 的单一 Riverpod Notifier 拥有业务事实；专注与习惯保留各自模型，页面通过公开 API 派生展示和发出命令。AppPrefs 新增 `yike_snapshot_v1`，保存版本、初始化日期、计时配置、会话、周期、历史、习惯与独立打卡身份；外观仍使用原有两项偏好。无接口、服务端或新增依赖，feature 不访问 MMKV。

专注按实际时钟累计有效毫秒；暂停不计时，到点封顶并停留完成态，不自动进入下一阶段。番茄完整轮次独立于历史记录数量，本轮休息类型在开始专注时确定、休息时长在休息开始时读取。正计时保留计圈，结束只入账一条总记录。倒计时完成必记，再计使用新身份。短记录先冻结、再确认；取消保持暂停或完成态。按来源会话防止重复入账，跨日用时按发生时的本地日期分配。

习惯新建、编辑、归档、恢复、删除和每日打卡均保存，同名不合并、改名不丢记录；删空后重开不补回初始习惯。草稿取消不保存，失败重试复用同一身份；名称校验可见字符和长度，提醒 `00:00` 有效。撤销只反转最新操作，并校验有效期、日期、对象状态及根导航代次，避免离开后快速返回重新启用旧操作。

回顾、今日汇总、类型分布、习惯详情与热力图都由记录推导。跨日记录在日期范围内按独立会话计数，月视图另算专注天数；日明细只显示分配给当日的用时与原始开始时间。设置精确保留秒数、空槽、顺序及开关；重置协调业务、外观、根导航、回顾选择和撤销反馈。

读取异常、损坏和未来版本快照阻止业务写入，保留原数据，可重试读取或明确确认重置。写入失败保留内存结果并显示未保存及重试入口；习惯编辑器保持打开。业务快照和外观偏好不是跨 key 事务，部分失败会提示并重试当前完整结果。

## 自查修正

自查修复了倒计时结束错误清空番茄周期、快速切走再返回仍可撤销旧打卡、归档 Sheet 关闭后使用失效 context 导航、Provider 作用域依赖缺失，以及跨日统计重复计算会话的问题。习惯保存失败不会显示成功并关闭，恢复暂停也不会重复补算已关闭时间。

冷启动只恢复最后保存的有效进度，并将运行态转为暂停；运行 tick 不写磁盘。未保存的一段进度仍可能在异常关闭时丢失，此处遵循产品现有规则，没有提高保存频率或承诺后台持续执行。
