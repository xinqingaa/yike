# 动效与布局连续性实施记录

日期：2026-10-23。依据 [六批实施计划](2026-10-23-motion-implementation-plan.md) 推进 Flutter 独立迭代；没有读取外部原型、修改 unified_popups、引入依赖或改动业务记账与恢复规则。

## 最终行为与落点

| 范围 | 本次实现 |
| --- | --- |
| 公共过渡 | `common/motion` 提供内容替换、尺寸衔接、展开及按身份变化的列表。退场内容不接受点击、焦点或读屏；减少动态效果直接呈现。切换偏好时保留当前正文和字段状态 |
| 可见性与事件 | `MotionGate` 同时提供渲染可见性和事件发生时的实时判定。完成适配直接监听已接受的快照转换，以会话/阶段和本次事件驱动本地动画；同帧隐藏/完成/返回及后台恢复校准均不补播 |
| 未保存 | `UnsavedStatus` 通过 AppPop 的 `Pop.custom(CustomPopupConfig)` 持有唯一句柄。提示不改变 Navigator 约束，可收起、展开、跨路由重试；业务与偏好部分成功时继续保留。嵌套模态通过实际 dismissed 生命周期挂起与恢复，表单保留就近错误 |
| 表盘 | 局部 Ticker 更新 `DialFrame`；静态原图通过 child 复用，机械指针和裁切使用 repaint/reclip，水位与日影的动态包装局部更新。数字按秒更新，共享文字度量与翻动相位；水面和反色裁切使用同一进度 |
| 边界 | 正计时整小时有 700ms 可观察满圈窗口，随后向前回绕；真实读数不受窗口影响。分钟涟漪与秒反馈分开，暂停停止节拍和翻数；长读数在固定安全宽度内缩放 |
| 导航与专注 | 根 Tab 正文与选中面使用相同控制器、240ms 配置和 gentle 曲线；模式确认后才过渡。动态效果偏好中途变化会直接定位。专注上下分区保持表盘锚点，辅助内容和操作宽度局部衔接；计圈独立滚动并按稳定身份插入 |
| 习惯与表单 | 三主题提供打孔、落滴和盖印反馈；新有效点击创建本地反馈身份，取消反向收束，快速重做接续，不排队。列表保存其它行身份与滚动；周目标、提醒、字段错误和设置保存错误局部展开，输入控制器及草稿保留 |
| 回顾与明细 | 日期和统计正文同向短衔接，快速翻期以最新范围为准；同范围数据刷新不创建整图入场。空态与类型分布局部展开；日期明细切日正文回顶部，外壳和翻日区保持 |
| 主题与启动 | 表盘读数位置和宽度沿图层权重连续混合，字体度量忽略颜色变化；主题不创建业务事件。启动准备后使用短淡入，不增加停留；减少动态效果后再关闭该偏好也不会回到启动页 |

业务 Controller、FocusEngine、快照格式、250ms 校准 pulse、保存检查点及异常终止策略保持现有职责。动画的逐帧输入和事件序号均由 Widget 生命周期拥有，不进入 Provider 业务事实或存储。

## iOS 原生过程

设备为 PB Phase4 iPhone 14，iOS 18.6 Simulator，390×844 逻辑尺寸、1170×2532 截图，debug 构建。[原生过程脚本](../../integration_test/motion_test.dart) 使用独立内存存储，不读写生产 MMKV。

三主题 × 正常/减少动态效果共六组原生过程全部通过，覆盖计圈、暂停、倒计时到点、快速打卡取消重做、根导航、回顾翻期/周月、浅深主题、未保存浮层与模态挂起恢复。每组采集七张分时画面，共 42 张；采集时点配合脚本断言使用，截图本身不证明精确动画相位。原生脚本完成后再复制到 `build/motion-verification/`；该目录为本机生成证据，不承载规范或提交资源。

已检查水位计圈与读数、日影计时、三主题回顾布局及深色未保存提示的画面；未将这组场景写成所有页面、输入法与辅助功能组合的全量视觉接受。

## 性能与存储边界

没有可连接的移动真机，本轮不报告 UI/raster 分位耗时或性能通过。新增 [真机 profile 采样入口](../../integration_test/motion_profile_test.dart)，要求 profile 构建和明确设备名称，输出刷新率、热身、样本量、UI/raster p50/p90/p99 与超预算帧；连续表盘、主题切换、计圈和根导航分别采样。它尚未在真机执行，也不提供当前代码的前后性能对照。

本轮没有修改存储实现、格式或业务写入路径，故没有重跑真实 MMKV 与两阶段进程重启专项；现有原生存储测试仍保留。故障测试证明的范围为内存接受、错误显示、重试幂等和恢复协调，不扩大为原生磁盘可靠性结论。

Android、真机 profile、原生大文字/输入法/读屏完整组合、最早系统启动帧和大历史数据压力测量继续保留在 [已知缺口](../known-gaps.md)。

## 指导使用反馈

没有安装新 skill。此次帮助最大的是 `flutter-add-widget-test` 的用户动作和可观察行为检查思路：中间帧、行身份和事件次数测试实际发现并修复了列表重建、布局断言和完成事件合帧误播。持续计时按仓库要求采用有界 pump，未照搬等待永远静止的示例。`dart-run-static-analysis` 用于收尾静态检查，`flutter-add-integration-test` 用于组织原生过程；沿用仓库现有 integration_test，不额外引入旧 Flutter Driver 入口。
