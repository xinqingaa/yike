## 用户要求与范围

- 结合一刻安静、简洁、低压力和桌面计时器实物感的定位，补齐专注、打卡、回顾、设置和表单中的运动过程。
- 正常动态效果下，页面内容和布局变化应有柔和、可中断的过渡；优先保持主要对象、操作位置与滚动稳定。减少动态效果时保留完整操作结果，直接呈现状态。
- 动效与业务尽量解耦，公共机制、主题表现和业务适配各有明确落点，便于定位和调整。
- 未保存横条改用 `unified_popups` 的完全自定义 API，实现非阻塞、可重试的应用级浮层。
- `unified_popups` 是用户维护的独立库，本计划沿用其公开能力，不开展该库的性能审计、整改或源码修改。弹层相关工作限于 Yike 的接入、内容和业务反馈。
- 可按实际需要自行绘制 SVG、增加 SVG 渲染依赖或转成 PNG，遵守本仓库资源规范。
- 暂不安装新的 skill；可以阅读和使用相关指导，实际制作后再反馈哪些内容最有帮助。

维持已有业务状态机、会话身份、记账幂等、250ms 校准 pulse、保存检查点和恢复规则。动画不等待落盘成功才呈现已接受的内存结果，也不通过动画结束回调提交业务。首批只做视觉，不增加触觉、音频、系统通知或其它产品能力。普通 Flutter 工作不读取原型、Vue 源码或调用 ProtoBridge MCP。

## 公共机制与业务边界

| 层次 | 职责与落点 |
| --- | --- |
| 公共运动机制 | 在 `lib/common/motion/` 提炼真实复用的可见性、内容替换、展开收起和列表变化机制；统一中断、退场命中测试、语义和减少动态效果策略 |
| 一刻视觉表现 | 三种表盘分别维护绘制，翻数共享实现；打卡效果留在 habits 的组件；保留设置预览和启动静帧的复用能力 |
| 业务与视觉适配 | feature 将会话、阶段和已接受操作转换为视觉输入及一次性事件身份；页面负责组合与发出意图 |

逐帧进度、Controller、Ticker 和绘制缓存由 Widget 生命周期拥有，不进入业务 Provider 或快照。公共层不导入 feature 的会话、打卡或存储实现。一次性完成以会话/阶段识别，打卡以本次有效操作识别；保存重试、主题变化、普通重建、读取历史和页面返回不创建新反馈。

时长与曲线沿用 `TS.motion`：读数和轻反馈用 `durationFast`，局部布局用 `durationNormal`，主题及完成收束用 `durationSlow`，面板和模式沿用现有专用时长。幅度、比例和节拍窗口集中到 [YikeMotion](../../lib/theme/yike_motion.dart)，不在页面散落常量，不手改生成主题。连续计时忠实跟随真实时间，布局运动采用克制、收束柔和的曲线，弹性按实际交互需要选用。

## 未保存提示迁移

### 展示契约

保留“持续告知未保存、说明关闭风险、提供重试”的职责，改为应用级自定义状态浮层。

| 项目 | 目标行为 |
| --- | --- |
| 事实源 | 合并业务快照 writeError 与偏好待保存项；不复制另一份保存事实 |
| 入口与归属 | AppPop 封装 `Pop.custom(CustomPopupConfig)`；应用层协调组件监听状态，拥有唯一浮层句柄 |
| 位置与大小 | 顶部安全区内紧凑浮条；页面尺寸与滚动保持，左右主要操作可达；窄屏和大文字下内容完整可访问 |
| 身份 | 固定 key，重复失败保持同一实例，不叠加、不重复入场 |
| 持续性 | 错误未清除时持续提示；允许手动收起为“未保存”入口，再次展开和重试；收起不清除错误 |
| 输入与返回 | 使用隐藏遮罩和忽略返回的配置；浮条外继续操作，不自动抢输入焦点 |
| 路由 | 跨根 Tab 和页面栈保留，由应用状态决定寿命；不跟随某个业务面板一起清除 |
| 重试 | 调用已有业务快照和偏好重试入口，保存同一最终结果，不重新创建习惯、打卡或结算 |
| 成功与部分成功 | 全部待保存内容成功后退场；部分成功时继续提示剩余未保存状态 |
| 模态优先级 | Sheet、确认框等当前操作优先；全局浮条暂挂起，保存表单保留就近失败说明与重试；模态结束后按最新状态恢复 |
| 主题与辅助功能 | 从当前主题和同一 ProviderScope 读取状态；支持文字缩放与首次失败的可读提示；减少动态效果时直接显隐 |

浮条不承担读取失败的阻断职责。读取失败继续保留现有页面、重试读取和确认重置流程，保护原文件。

### 生命周期与实现约束

监听与协调放在应用层，公共浮层组件只接收展示内容、状态和回调。业务页面继续通过 AppPop 使用弹层，底层句柄不散落到 feature。需要模态展示状态时，通过 AppPop 的实际打开、挂起和 dismissed 生命周期协调，支持嵌套，不以固定延时猜测退场完成。

展示请求延后到安全的帧时点并复查 mounted、请求身份和最新错误状态。偏好同步保存已成功时不闪出提示；浮层尚未展示就恢复时取消待展示请求；退场期间再次失败时，旧关闭回调不能清除新提示。重建、切主题和重复重试不重新入场。应用边界释放、读取阻断及成功重置时正确清理自己拥有的句柄。

普通 Toast 与未保存浮条不改变专注的可见性判定。进行模态操作时抑制背景一次性反馈，业务计时继续；关闭后直接承接当前状态，不补播错过的事件。以上只涉及 Yike 的呈现策略。

主要入口为 [LocalDataBoundary](../../lib/app/local_data_boundary.dart)、[AppPop](../../lib/common/overlay/app_pop.dart)、[app.dart](../../lib/app/app.dart) 和 `lib/common/overlay/`；业务快照与偏好继续复用现有 [LocalDataController](../../lib/features/local_data/providers/local_data_provider.dart)、[PreferenceWriter](../../lib/storage/preference_writer.dart)。

## 全应用场景契约

| 场景 | 实施目标 | 稳定性与中断要求 |
| --- | --- | --- |
| 根 Tab | 沿用现有 TabBarView 做短水平衔接，正文与导航选中面同步 | 保留禁止手动横滑、页面身份、滚动和局部状态；连续切换承接当前过程 |
| 计时模式 | 确认处理后，选中面与内容同向过渡 | 取消不提前移动；业务处理不依赖转场结束 |
| 专注布局 | 待开始、运行、暂停、完成、休息之间，按钮标签、数量、宽度、计圈和辅助内容共同衔接 | 优先稳定表盘与主操作锚点，必要位移有过渡；窄屏和大字体下操作可达 |
| 读数 | 相邻一秒且同会话时仅变化位翻动，冒号静止、等宽槽位 | 新数位出现时处理宽度、字号和位置；后台恢复、大跨度和对象更换直接定位；暂停立即冻结 |
| 机械 | 指针与扇面使用同一时间投影，秒反馈极轻、分钟略明显 | 明确整小时满圈的可观察窗口与回绕方向，避免依赖某帧恰好命中边界或整圈倒放 |
| 水位 | 水面、裁切与上下读数共用输入及翻数相位；秒反馈与分钟涟漪分别控制 | 暂停/完成停止节拍，读数仅暴露一份语义；减少动态效果关闭装饰 |
| 日影 | 阴影跟随真实进度，秒明暗和分钟反馈克制 | 暂停/完成静止，浅深材质与主题切换连续 |
| 阶段完成 | 会话/阶段发生完成转换时一次轻收束和文案过渡 | 以业务状态为准；不可见、初始化完成态、返回和保存重试不播放 |
| 打卡与撤销 | 机械打孔、水位落滴、日影盖印，结果立即生效 | 取消/撤销承接当前画面；新的有效打卡可再次反馈，快速操作不排队 |
| 计圈 | 列表顶部局部插入，原行短移位，使用稳定身份 | 保留独立滚动，不挤动表盘与操作，暂停冻结当前读数 |
| 习惯列表 | 新增、归档、恢复、删除只过渡受影响项目 | 保留顺序、其它行身份与滚动；取消不改列表；隐藏期间的变化返回时显示事实，不补整组入场 |
| 表单与设置 | 周目标、提醒时间、校验和保存错误平滑展开，选择结果局部衔接 | 草稿不丢失；键盘、焦点滚动和固定操作区协调；失败不提前关闭 |
| 回顾翻期 | 日期与图形同向短衔接；周/月不同高度、空态和类型分布局部过渡 | 连续翻期以最新范围为准，导航占位稳定，统计正文不翻数，数据刷新不重播整图 |
| 日期明细 | 日期和正文衔接，新日期正文回顶部 | 外壳、关闭与翻日区固定；不改变来源滚动及图形高度，空日和日期边界规则保留 |
| 主题 | 颜色、图层、读数位置与外形共同过渡 | 同一业务时间与事件进度，不重置会话、草稿、滚动；减少动态效果直接呈现 |
| 启动 | 准备完成后衔接内容，核对已保存主题与品牌静帧的连续性 | 不人为增加停留；返回前台不重播启动；最早系统启动帧未核验项如实保留 |

任何过渡的退场内容都需要处理点击与读屏，避免旧按钮仍可提交或重复语义。连续反向、对象替换和快速操作承接当前画面；减少动态效果中途开启立即结束装饰并呈现结果，关闭后不补播。

## 更新隔离、资源与测量

保留现有表盘外层 RepaintBoundary，按不同更新频率继续拆分。RepaintBoundary 隔离绘制，不阻止其内部 Widget 重建；缩小 build、layout 和 paint 范围分别处理。

- 静态原稿、刻度和杯壁与连续进度分离，稳定子树通过 child 复用；适合直接绘制的部分由 CustomPainter 的 repaint 监听驱动。
- 连续表盘按帧绘制，读数按秒变化，文案和操作按业务状态变化；逐帧不重建根页面、不重算历史、不更新业务 Provider 或存储。
- 翻数上下副本共享文字度量和相位；几何与文字缓存以字体、文字缩放、主题、尺寸为有效条件，变化时正确失效。
- RepaintBoundary 按重绘频率差异设置，通过绘制观察和测量确认收益；保留既有列表或组件已经提供的边界。
- 隐藏或暂停时停止相应装饰 Ticker，恢复直接定位；静止时不运行无用的持续装饰帧。Controller、Ticker、监听和浮层句柄都有唯一清理方。

当前核对到 55 个图标和 22 张表盘/状态图层，首批优先复用；数量仅代表本次基线。简单运动几何可直接自绘。新增 SVG 可按需要增加渲染依赖，或转为 PNG；资源放入既有 `asset/` 归属，登记本地类型化映射、pubspec、逻辑尺寸、浅深模式和来源说明。导入清单与生成资源的维护边界继续遵守 [资源规范](../engineering/assets.md)，新增本地能力不触发外部同步。

测量针对 Yike 的表盘、主题过渡、内容转场和列表场景，记录真机、构建模式、刷新率、热身、样本量、UI/raster 的 p50/p90/p99 和超预算帧；60Hz 预算约 16.7ms，120Hz 约 8.3ms。用相同场景比较调整前后，不能把静态代码形态、平均 FPS、模拟器或 debug 感受当成真机性能结论。没有真机时继续完成独立工作，明确留下待测范围。

Widget 测试注入 clockProvider，在确定时间点检查初始、中间和最终状态、位移、裁切、静止及事件次数。持续运行场景使用有界 pump，调整相关旧测试和 helper 对 pumpAndSettle 的依赖，不通过全局禁用动效掩盖过程问题。核对旧测试对完整数字 Text、文案数量和布局尺寸的依赖，拆分读数时保留同步裁切、单份读屏和稳定尺寸的检查。新增测试验证用户可观察行为，不镜像实现细节。

工程收尾运行 `node tool/verify.mjs`。原生运行检查实际操作过程，录屏或分时截图配合脚本记录；单帧不证明连续性。使用隔离测试数据，已有真实 MMKV 和进程重启测试按受影响范围执行，测试替身不替代存储声明。详细命令与测试职责见 [测试与视觉验证](../engineering/testing.md)。

交付分别报告代码检查、行为测试、原生过程和真机测量。批次完成时更新 [动效规格](../product/motion.md) 与相关 UI/工程规范；未完成项更新 [已知缺口](../known-gaps.md)，已决定的体验变化按 [工作流](../workflow.md) 归入相应决策记录。历史评审保持原有时间范围。
