本次按用户批准在 Yike Flutter 端直接修复，不调用 ProtoBridge MCP，不修改 Producer、固定 Evidence 或历史评审。现有 `.codex/config.toml` 和 `.mcp.json` 用户改动保留。

## 实施结果

| 范围 | 结果与落点 |
| --- | --- |
| 表盘字体 | `theme_interpolation.dart` 补齐三种数字文字角色；主题与明暗动画期间不再回退到默认字号、行高、字重 |
| 滚轮 | `wheel_picker.dart` 将单位定位到数字右下，按实际文字宽度布局，保留整列的滚动与点击区域 |
| 习惯热力图 | `habit_heatmap.dart` 提供可读方格、星期与月份定位；全年横向滚动，初始显示最近日期；完成事实优先于归档外观 |
| 回顾 | 周/月选择和周期导航分行；空周期保留日期框架与零值，未来禁用；周/月显示当日打卡次数，月历计数在图形下方独立占位 |
| 弹层 | AppPop 保留统一调用入口，内部按 toast、confirm、sheet、flowSheet、loading、menu 拆分；外壳统一左右留白，header 移除库默认上下留白，正文与页脚不重复加横向 Padding |
| 计时切换 | 禁用滑动；PrimaryTabs 的受控请求路径不提前移动 controller。未处理会话先显示目标模式和后果，仅保留有间隔的“放弃”“结束”两个常规按钮，默认不显示分隔线 |

关闭、遮罩和系统返回均取消模式请求，保持原页面、模式及会话运行/暂停状态。结束时仍执行原有短时记录确认；取消短时确认留在旧模式暂停态。确认处理完成后才切换目标模式。减少动态效果时主题、Tab 和 Sheet 直接进入结果状态。

回顾空态移除“去专注”按钮，采用底部导航引导。它与历史固定空态截图存在经用户批准的差异，详见 [已知缺口](../known-gaps.md)。
